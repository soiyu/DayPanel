# ADR 0013：桌面直接操作

2026-11-07。用户指出桌面组件还要打开具体页面才能操作，修正FL16交互。

- 布尔习惯和小事主体/主按钮直接执行明确完成或取消完成，广播只投递系统JobScheduler，独立:widget_actions进程启动无界面的Flutter引擎。全部业务写入继续由Dart AppStore既有事务/计划/常驻/成就规则完成，原生不写业务库。保存后同UID Provider重排提醒、刷新组件，App前台/恢复读取最新数据。无通知权限或前台服务要求；系统队列可短暂延迟，组件显示处理中/失败/刷新后的真实状态，不把点击当成功。
- 静态PendingIntent包含实例、配置token、generation、日期、明确目标和当前业务revision，是显示上下文而非物理点击ID。SQLite10在原设备运行态runtime新增revision；相关业务表插入/更新/删除触发单调递增。同一事务核对generation、revision、当前值和日期后写入；重复请求、ABA和恢复前动作不能覆盖新记录。全库相关数据revision属于保守并发检查，无关事项变动可能使旧动作要求重试，不推测撤销。
- runtime revision与既有generation都是本机运行态，不随备份/恢复回退；恢复单事务递增generation，触发器继续递增revision。备份schema10无新增用户表，严格接受schema2–9并升级封套；导出/恢复前副本/回退沿用全部用户表。业务库迁移只加运行态字段/触发器，提醒读取3..10，组件7..10。旧库未迁移时直接动作禁用并提示打开App更新。
- 布尔取消完成清除当天记录，常驻取消只清当天，一次性重新待办清原完成日。保留已获卡/快照；休息/归档/对象删除/旧日期拒绝。完成仍使用既有当天卡片规则，历史不发卡。后台没有Activity视图，声音/触感不主动触发；桌面状态为反馈，App内偏好行为不变。
- 数量主体/按钮一步直达现有总量输入，确认后写。单独WidgetQuantityActivity隔离旧详情Activity，不经详情页；不自动累加，取消不写。配置也使用独立Activity，避免未关闭详情拦住配置。详情是独立小按钮，主体优先操作。当前未保存的数量表单仍保留目标，不静默切换输入对象。
- 后台请求每次执行检查真实绑定，任务成功/拒绝/失败均刷新与同步提醒。中断后系统重投因revision检查安全，已提交但未刷新可由重投补刷新。系统停止/重启限制如实记录，不能承诺厂商后台全部可用。
