# ADR 0007：FL15 打卡表、统计、年历与时间线

2026-11-06，用户授权继续下一批。只统计真实本地数据，不增加专注或自动采集。

- SQLite7新增habit_activity，保存习惯归档状态的日期版本。同日操作覆盖当天状态，次日后的统计保留旧状态；归档当天从分母排除，恢复当天按计划计入。旧库只能从升级当天建立基线，之前归档履历未知，保留记录但不推定缺席/失败。新建习惯从开始日已知。备份schema7包含履历，兼容schema2–6时从备份的本地创建日建立基线（不早于开始日）；旧库不能重建的计划/归档改动在页面说明。
- 打卡表按周呈现多习惯×日期，可切周和定位日期；区分完成、已记录未达标、未记录、未安排、弹性周目标、履历未知、未来/未开始。默认含归档习惯以保留历史，可筛选单习惯；点击单元格打开明确日期的记录面板，显式完成/清除或数量保存，不点格即写。当前归档仍禁止记录；未来和开始日前只读。恢复后的旧面板受generation保护。
- 单习惯统计可选近7/30/365日（包含今天）。完成率仅算已结束的日期（至昨天）、履历已知且活跃、每日/星期/间隔计划的应做日，分子为对应历史目标达标日。零分母显示无可统计计划日。今天未结束不算失败，计划外记录、归档期、未知期不混进完成率。
- 每日连续性按范围内应做日计算，不安排日跳过；未知履历、归档、切入周目标会中断。今天未完成暂不打断已有连续性，今天已完成可延长；最长与当前均标明仅在所选范围内。周目标单独按完整自然周统计，每周需7天都在范围内、同一计划且履历已知活跃，周中起始/改版/归档/恢复的部分周不进周完成率或连续周，进行中的本周不记失败。每日与周统计不混分母。
- 数量按单习惯、历史单位分开汇总和绘制逐日趋势，不换算不同单位，不跨习惯相加。同一单位的不同目标版本可合计实际值；均值为有记录日期的平均值，零值算已记录，未记录不填零。显示每一天的实际值、当时目标、单位和可纠正入口。
- 年度日历以真实习惯记录数着色（含零值），支持年度切换和单习惯筛选，日期可查看当天明细；不以颜色伪称完成率。未来日期灰显不可写，闰年按当地日历计算。日期定位可直达任意支持年份。
- 时间线按记录日汇总习惯记录、一次性实际完成日、常驻完成日、手记与获得的卡片；同日按类型/ID稳定排序，不编造时分或审计日志。支持月份/日期和类型筛选，条目打开真实编辑/详情；重开/删除后的已消失事实不继续展示，卡片快照仍独立保留。
- 新页面从“我的→统计与历史”、七日回顾和习惯详情进入，复用蓝/紫/暖橙组件。保留七日回顾的原始计数语义。界面中英文、明暗、窄屏大字号、键盘和真实空态一并验收。
