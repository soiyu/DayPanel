# ADR 0005：关联日志、按月浏览与搜索

2026-11-06，执行 FL13。手记继续是独立文本记录，也可以明确关联一个习惯和一个实际记录日期。

- `notes.day` 是用户选择的本地日，新增手记默认今天，编辑时日期和关联习惯都可修改；可记录 1900 年起至今天的日期，不创建未来日志。日志不要求同日存在打卡，也不受习惯开始日约束，因此可补写习惯建立前的相关经历。它不改变任何完成事实。同一天可以有多篇，正文最多 10000 个字符；保存前取消、返回或关闭面板均不写入。
- `notes.habit_id` 可为空。空值表示独立手记；关联值只引用当前习惯。习惯归档保留关联文字和引用，详情与手记页显示已归档状态；归档后仍可写/编辑日志。永久删除习惯通过同一 SQLite 删除事务的 `ON DELETE SET NULL` 解除关联，习惯及其打卡数据删除，日志文字和日期保留。删除确认明确说明这一点。
- 手记页默认本月，支持前后月和全部月份；日期定位跳到该月并限定所选日，可一键查看整月。月份/单日、习惯（全部/独立/任一含归档习惯）、正文搜索同时取交集。搜索为去掉首尾空白后的连续子串，不区分英文大小写，百分号/下划线按普通文字匹配；不搜索习惯名。无结果明确提示可改变条件。清除筛选去掉关键词、单日与习惯，保留当前月范围；全部月份用于跨月搜索。
- 浏览条件在切换标签/返回时保留，重启默认本月、全部手记、空搜索。成功保存会显示该记录月份并清除筛选，让新建/移动日期后的手记可见；取消保留原条件。日期倒序，同日按稳定 ID 排序，恢复后顺序稳定。
- SQLite 升到 v5，在 notes 增加外键和日期/习惯索引，v1–v4 原文字/日期/ID 保留。备份升级为 schema5，新增 `notes.habit_id`，兼容 schema2/3/4 时补空关联；严格校验字段和引用但允许关联归档习惯。恢复、回退及旧恢复副本同样兼容，旧编辑和删除确认携带 generation。原生 SnapshotReader 兼容范围同步为 3..5。
- 关联日志入口放在习惯详情，新增、查看、编辑均复用手记编辑面板；独立手记仍可从手记页创建。所有写入使用显式日期和关联值，重启后从 SQLite 重新加载。

流程：用户在习惯详情点“写日志”（预填详情选定日和习惯）或在手记页点新增（默认今天、独立） → 编辑面板选择日期与可选习惯 → 保存事务写入 → 手记页定位保存月份。删除习惯时外键解除关联；删除手记仅删除该条文本。搜索、月份、习惯筛选不修改数据。
