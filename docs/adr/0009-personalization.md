# ADR 0009：FL17 免费外观与习惯装扮

2026-11-06，继续执行下一批。所有选择免费、离线，无下载商店、账号或收费入口。

- 外观页提供跟随系统/浅色/深色、晴空蓝/林间青/暮色紫三种主题、系统字体/本地 Noto Serif SC 字体、默认图标边框。页面内使用临时 Theme 预览真实用户习惯或明确标记的文字排版样张，选择不写库；保存一次事务应用，取消/系统返回不写入，恢复默认先改变预览再由保存确认。旧外观页携带 generation，恢复后不可写入。
- 习惯图标扩充到24个，前六个索引和含义保留。习惯可单独指定自动/蓝/紫/橙/青/玫瑰配色，以及跟随默认/柔和底/圆环/无边框。颜色是装饰，完成/未记录/归档仍有独立文字和图形。习惯编辑即时预览；保存装扮不创建新计划、不改历史记录或重新发卡。
- SQLite8给habits增加color和frame（默认auto），原记录与icon不变；settings保存palette/font/icon_frame。备份schema8严格校验全部枚举与图标范围，导出/导入/恢复前副本/回退同步包含，兼容schema2–7为新增字段补auto，旧文件没有外观设置时使用原默认。未知值拒绝导入，运行时读取未知设置安全回默认。原生ReminderSnapshot支持3..8，组件读取器支持7..8。
- 字体随APK打包，来源与OFL版权声明保存在assets/fonts/及NOTICE，并加入App许可证页；不运行时联网下载。系统字体为默认，用户系统大字号和减少动画继续生效。桌面RemoteViews保留Android系统字体，主题主色与习惯装饰同步刷新；不承诺平台不能实现的自定义桌面字体。
- 主操作按主题使用可读的深色渐层与白字，回顾紫/日期橙的语义保持；主题改变背景和主操作，不把每个信息层都刷成同一颜色。预览、固定保存/取消、空态、中英/明暗/320dp大字号/键盘与屏幕阅读语义一起验证。
- 不扩展到壁纸导入、任意网络字体、桌面启动图标切换或自定义图片；这些没有本批授权的数据与权限设计。原生桌面绑定仍是本机状态，不进入备份。
