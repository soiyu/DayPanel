# ADR 0012：事项模板、图标语义与组合主题

2026-11-07。用户明确要求修正事项/图标无关联、缺少默认事项和合理数量、图标单调、主题整体换色的问题。

- 新建习惯先选本地常用模板或自定义。模板含名称、图标、类型、数量/单位、时段，每日默认。喝水1500毫升、阅读10页、步行6000步、拉伸10分钟等为可编辑起点，不是健康处方。选择只填草稿，保存才创建，取消不写；安装不强塞记录/习惯。手动分钟记录不引入计时器。常见单位的快速填写改为常用总量（毫升250/500/1000及目标、页1/5/10及目标等），按当日历史计划的单位/目标生成，去重且不超过目标；只填输入框，确认才写，不盲目累加。
- 自定义新建按明确中英文关键词匹配图标，只有未手选图标时跟随名称；仅图标变化，不猜目标/单位。已有习惯不自动重写，允许用户查看匹配建议后主动应用。模板不覆盖已有习惯，不改变历史计划规则；旧恢复页面沿用generation保护。
- 保留24个持久化图标ID及原有语义，以原创多色生活物件图替换Material字形。独立配色不跟主题变成单色；手选颜色用于图标底框和条目强调。Flutter与Android桌面复用相同本地PNG，源绘制脚本可复现，无外部IP素材/联网下载。
- 主题仍用blue/teal/violet稳定ID；改为完整调色组合，背景/表面/功能色/装饰色配对，不做整页主色滤镜。日常蓝、记录紫、事项橙和辅助青保持识别；三主题有不同底色温度与配对。图标物件本色独立，深色保持对比。
- 无数据库字段/版本变化：SQLite9/schema9、备份字段/旧版本兼容保持；模板属于应用目录，用户保存后是普通习惯，导出实际名称/数值/图标/装扮，不保存设备无意义状态。
