# ADR0014：按场景组织产品能力

2026-11-08。用户授权全面梳理不合理功能并修改，范围由PM01-FUNCTION-REVIEW记录。

- 区分单日记录、历史回看、整项管理。HabitDetails持有进入时的generation和initialDay，所有入口传所选日期；设置独立HabitManagementPage，提醒/休息/可选手记/计划历史/归档删除在管理上下文。
- 数量仍为整数千分位的累计总量，预填值只填草稿；明确替换目标值、保存才写、取消不写。不在本次增加逐杯事件或从旧值猜累加，避免未设计的重复/并发语义。
- 已有类型不可变，UI只读表达；整理与装扮按需展开，目标/频率次日生效明确。跳过只有已计划且无记录时可选，周目标确认明确该周不考核完整周目标，底层休息规则不变。
- 常驻今日记录与历史纠正分层，一次性标题统一进入详情。所有缺失/恢复失效页面显示返回入口，不重建对象。捕获generation防止旧页面在恢复后编辑同ID的新内容。
- 统计适用性依据范围内历史计划，不看今日类型猜过去。量化先展示真实数量趋势，纯周目标不展示无意义日考核；混合历史各自统计。没有日义务且无已获卡不展示解锁承诺，已获卡与快照继续保留。
- SQLite10/schema10无变化；不删除功能底层数据，不复制Loop实现，无SDK/权限/账号/云/付费变更。外部用户走查不是实施前置，工程和隔离用户设备验证继续。
