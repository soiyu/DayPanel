# ADR 0006：FL14 成就卡、收藏、心得与反馈

2026-11-06，用户授权继续执行下一批。沿用既有免费、无专注和 Android 范围。

- 当地日每天最多获得一张卡。当天有效计划中所有未归档、已开始且安排在当天的每日/星期/间隔习惯全部达标且至少有一项时可获得；周目标是弹性安排，不计每日必做；分组和情境筛选不改变判定。数量按当天计划版本的目标比较，不混合单位。
- 当天实际保存习惯值并首次从未达标变为达标时，在同一SQLite事务中核对全部计划并自动发卡；也提供“领取今日卡片”供已达标但还没领卡的用户主动领取。领取在事务中重新校验当天与全部计划，不凭UI预览写入。未来/历史补记不发卡，迁移/启动/恢复/归档/删除/编辑不自动发卡。归档或删除后主动领取，以当时当前未归档计划为准；空计划和仅周目标不发卡。
- 卡片是解锁当时的纪念，不是可回收的合规证明。撤销、降低数量、添加新习惯、后续改计划、归档或删除都不撤回已获得卡片、收藏或心得。保存当时参与的习惯ID、标题、类型、目标、单位、数值与计划生效日快照，删除习惯不级联删除卡片；页面展示快照与说明。每天一张唯一键，重复保存/领取幂等。
- 六张原创Flutter绘制的自然/生活主题插画按本地日期确定性轮换，不随机抽奖、不设稀有度或收费。收藏为显式布尔值，可筛选收藏；卡背心得0–10000字，保存才写入，空文本可清除，取消/返回保持原文。所有新写入和领取携带generation，恢复后旧页面拒绝写入。
- SQLite v6新增cards表；备份schema6包含卡片、快照、收藏、心得与反馈偏好。严格校验新字段、日期、插画范围、布尔、文字长度和快照；兼容schema2–5及旧恢复副本，旧库不编造历史卡片。SnapshotReader同步兼容3..6。
- 反馈仅在当天用户保存从未达标变达标后触发，失败、取消、重复显式值、清除、补记、启动和恢复都不反馈。声音和触感分别可关闭，默认都关闭；设置持久化并进备份。原创短提示音为本地合成WAV，Android SoundPool播放并尊重系统静音/勿扰/音量；触感遵从系统触感开关。平台反馈失败不回滚数据或谎称保存失败，不延迟补播。
- 日常显示实际卡片状态、可领取入口和查看入口；我的提供卡片册与反馈设置。卡片详情可翻面、收藏、编辑心得、查看当时完成快照；动画尊重系统减少动画，文字/按钮不依赖声音与颜色传意。中英明暗、窄屏大字号、键盘、空态与错误一起验收。
