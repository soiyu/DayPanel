# ADR 0008：FL16 Android 桌面组件

2026-11-06。两类 RemoteViews 组件，每个 Launcher 实例绑定一个习惯或小事；可添加多个实例、缩放、重新配置及移除。只做 Android 桌面，不承诺锁屏或 iOS 能力。

- Android 只从 SQLite 一致事务快照读取当前日期、实际记录、日期对应计划和设置，不写业务数据、不创建或升级业务库。写入通过直接 Activity PendingIntent 启动 Flutter 组件页，调用现有 AppController/AppStore；数量直接打开总量输入面板，取消不写入。布尔及任务主操作只设置明确的完成值，不提供桌面切换/快捷撤销；已完成时进入真实详情进行用户主动纠正。
- 独立 WidgetActivity 承载配置/记录界面，复用现有主题、组件和数量面板。组件 Activity 使用独立 :widgets 进程和 SQLite 连接，避免 sqflite 单线程池跨引擎事务互相阻塞；显式退出关闭连接。多个 Flutter 引擎各用独立 SQLite 连接，所有 AppController 写入在同一事务中检查 generation，并通过事务上下文调用既有存储规则，避免检查与写入之间发生恢复。卡片同事务解锁，随后通过同 UID Provider 在主进程的原有工作队列同步提醒及全部组件，提醒运行态仍由主进程独占管理；主 App 恢复前台重新读库。SQLite 和备份继续 v7/schema7，不增加用户数据字段。
- 设备绑定通过不导出的同 UID ContentProvider 由主进程唯一管理，避免多进程 SharedPreferences 缓存分歧；底层保存在私有 SharedPreferences，以 appWidgetId 为键，含类型、对象 ID、generation 和随机配置版本。绑定不进文件备份，也不转移 Launcher ID。重新配置更换配置版本；取消保留旧配置；删除实例清理其绑定。恢复/回退后即使对象 ID 相同也显示需要重新选择，旧动作拒绝。不复制出不存在的 Launcher 实例。
- PendingIntent 身份包含实例 ID、配置版本、generation、显示日期和动作；不可变，实例之间不覆盖。这些字段表示显示上下文，绝不冒充物理点击 ID。重复完成请求仍是相同显式值；不在原生实现增量或撤销。执行时重新校验实例绑定、对象、generation、当地日期和类型；失效动作只显示提示并刷新。
- 每次 App 成功操作、前台恢复、组件配置/尺寸改变、系统周期更新、开机、覆盖安装、日期/时间/时区/语言改变都会读取新快照。午夜使用系统普通闹钟重排，组件不申请通知或精确闹钟权限；Doze/厂商节电可能延迟显示，日期始终写明，旧日期动作拒绝并刷新。强停会阻止系统唤醒，重新打开 App 恢复，不声称绕过平台限制。
- 历史计划只用于对应日期。周目标显示本周已达标日/目标，不写成每天必须完成；常驻显示今天是否记录，次日无记录不产生欠账；一次性显示实际完成日或计划日。归档只读，删除/未知版本/读取失败为明确空态与配置/打开入口，不显示伪造记录。
- 浅深主题及中英文跟随 App 设置或系统；冷白/蓝/淡紫/暖橙、细边渐层、圆角和清楚点击区域。窄尺寸保留日期、名称、状态和主操作，较大尺寸补充规则说明；完整文字通过读屏描述和详情可达。工程验证与真实 Launcher 的添加、配置、点击、缩放分别记录，模拟器不代表厂商真机验收。

组件 Activity 单实例，未关闭的表单仍显示原名称和日期；再次点击不会替换当前输入对象。需要先保存或取消，再打开另一组件。
