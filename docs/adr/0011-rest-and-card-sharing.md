# ADR 0011：UX01 休息安排与成就卡图片

2026-11-07。用户同意提升日常体验，执行暂停/休假/跳过及卡片图片分享。延续免费离线与UI02视觉。

- SQLite9新增habit_breaks(id,habit_id,start_day,end_day,kind)。pause从今天至手动恢复、vacation为明确未来/当天起止日期、skip为单个今天或过去日期。日期包含首尾；无重叠、不能早于习惯开始日，休假最多365日且结束不超过2200年。旧库无记录，不推造历史暂停。永久删习惯级联清理，归档保留。
- 暂停/休假不删除已有记录，实际数量与时间线事实仍保留；休息日期不纳入每日应做分母、不算完成，连续计划日中性跳过。受休息影响的周不纳入完整周考核、连续周中性跳过，不缩减或伪造周目标。当天有休息标记时不接收新记录（包括组件旧动作），用户需先结束/取消；单日跳过要求该日无记录，不悄悄删原值。
- 当天及未来可取消/提前结束休息，历史范围保留。提前结束只把结束日设为昨天，今天开始的则删除；未来休假可取消，历史单日跳过允许明确取消。操作携带generation和原id/结束值，重复不切换，不提供按当前值猜测的撤销。时钟退回已存开始日前不将其当作进行中恢复。
- 休息不改变计划版本；提醒eligibility忽略休息日，恢复/到期自动按原计划工作。无限暂停不创建到期闹钟，手动恢复触发重排；有期限休假<=365日，现有查找窗口覆盖。Widget显示暂停/休假/跳过与查看入口，冷进程只读9库；Dart提交仍事务检查。
- 成就卡只依据当天非休息的按日义务、至少一个实际达标项。设置休息不自动发卡，只有既有记录达标转换或主动领取；全部休息不发卡。已获卡片及快照保留。备份schema9包含breaks，严格校验字段/引用/日期/kind/重叠/重复，兼容schema2–8补空；恢复前副本和回退同样支持。提醒读取3..9，组件7..9。
- 分享页显示原创卡面、日期、标题与已获卡片的完成项数；习惯名称/心得默认关闭，可明确选择，名称最多6项其余标数量，心得作为用户可编辑的最多280字摘录，不修改原心得。图片预览即输出内容，支持中英文/主题；导出为PNG、通过SAF保存，无相册存储权限。系统分享使用私有缓存+不导出FileProvider、临时URI读授权，用户自行选择接收App，本功能不直接发送消息。缓存过期清理，备份不含临时PNG。
- 分享只读卡片，不解锁新卡。页面保存/分享前检查generation与原卡片仍存在，旧恢复页面失效。取消不写卡片/不发消息。失败可重试，只有保存文件成功才提示已保存，不把打开分享面板当已发送。
