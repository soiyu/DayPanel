# ADR 0002：M2 安排历史与完整备份

2026-11-05，按“下一批任务”执行 FL09/FL10。

- SQLite 升到 v2，旧数据原地迁移。习惯新增情境（不限/早晨/白天/夜晚）、可选分组及显式排序。独立计划版本存储目标、单位、频率；旧 v1 只能以迁移时参数建立起始版本，不编造迁移前修改历史。
- 新习惯从当天开始。已有习惯的目标/单位/频率调整从明天生效，同日多次编辑更新明天版本；历史列表、完成判定、数量面板使用记录日期对应计划。旧计划按日历日计算，不用毫秒除法处理 DST。
- 支持每天/指定星期、每 N 天（1–365，从该版本起始日计）、每自然周 N 个达标日（1–7，周一开始）。周目标非指定必做日，按“本周可记录/已达标”表达；每日数量达标算一个达标日，不跨天相加。版本在周中变化时该版本的首周从生效日起计并标明，不跨版本凑次数。
- 分组删除仅解除归属，习惯和历史保留；重排必须是完整、无重复 ID 列表并在事务里保存。过滤影响视图，不影响全局统计分母。
- 完整备份采用有版本与 SHA-256 的 UTF-8 JSON 信封，含全部用户表、计划、分组、记录、任务、手记、语言与主题。通过单次 SQLite 读事务取得一致数据，不复制活动 WAL 文件。校验和用于完整性，不是加密/签名。格式上限 8 MiB、总行数 100000。
- Android SAF 导出/选文件，不要存储权限。取消不改数据；读取后先严格校验、预览数量与时间，明确是替换而非合并。旧 Loop 数据格式不兼容此文件。
- 恢复在单 SQLite 事务中先保存恢复前逻辑快照到 recovery 表，再替换全部用户表、增加数据世代；事务失败/进程中断由 SQLite 回滚。恢复后可回到恢复前快照（只留最近一次），回退也在事务中完成。测试异常注入及独立进程中断，不能声称断电/所有提供器已验收。
- 版本与世代 token 拒绝仍打开的旧编辑页面跨恢复写入。数据操作统一锁定；外部文件选择/预览期间仍可取消，事务提交期间禁止退出。备份文件不包含历史 recovery 快照或机器路径。
- UI 继续使用既定三色组件。我的→数据与备份；日常→情境/分组筛选；习惯编辑→安排与整理；管理习惯→分组管理和排序。全部免费，不增加提醒/专注/账号/Billing。
