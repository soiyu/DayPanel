# ADR0018：云优先、个人主体与一次性订阅消息

2026-11-16。用户明确：数据直接上云、不存本地；主体为个人；iOS 微信小程序是否单独申请；提醒走微信订阅消息（询问是否只有一次性）；无需桌面组件；无需迁移旧程序。

本 ADR 修订 [ADR0017](0017-wechat-mini-program.md) 的本地优先方案；ADR0017 保留为初始提议记录。

状态：云优先/提醒限制/无桌面/无迁移仍有效；Plus/虚拟支付部分被 [ADR0019](0019-free-ads-reminders-no-export.md) 取代（v1 全免费、后续广告）。

## 决策

1. **云优先，不存本地业务数据**
   - 使用微信云开发（CloudBase）数据库 + 云函数 + 云存储导出。
   - 小程序端不写 SQLite/本地 JSON 业务文件；只在内存保留当前页/会话数据。
   - 按页面读取、分页、服务端聚合；不把完整状态拉到客户端（小程序查询 20 条、响应 1 MB 限制）。
   - 写入统一走云函数 `api.mutate`，以 `dp_meta.revision` 做乐观并发；云函数事务写少量文档。
   - 断网不可用；显示网络错误/重试，不做假离线。
   - 开发者可通过云控制台访问数据；不是端到端加密；隐私定位必须重写。

2. **个人主体 + 虚拟支付**
   - 个人主体在类目含“工具”、实名、备案后，可申请小程序虚拟支付；公开资料显示月收款限额约 10 万元，费率以 MP 后台为准。
   - Plus 一次买断使用 `short_series_goods` 道具直购；权益按 openid 存云端；不跨 Google Play/微信号。
   - iOS 不需要单独注册小程序，也不需要开发者单独向 Apple 申请；微信已支持 iOS 虚拟支付（2026-02 官方公告，15% 优惠费率），但需在 MP 后台开通/配置。
   - 若资质/审核未通过，先发免费核心版；不伪造购买或静默解锁。

3. **提醒只按一次性订阅设计**
   - 个人工具类不能申请长期订阅；长期订阅仅限政务/医疗/交通/金融/教育/设备等类目。
   - 一次 `wx.requestSubscribeMessage` 授权只能下发一条；“总是保持”只免弹窗，不增加额度。
   - v1 只做“本次提醒/每日摘要（用户当天授权下一条）”；不承诺每日自动、多时刻必达。
   - 若必须每日固定提醒，需另行确认系统日历混合方案；否则 v1 不做提醒。
   - `dp_jobs` + 定时云函数 + `cloud.openapi.subscribeMessage.send`；明确 pending/sent/invalid/failed 状态。

4. **移除桌面组件**
   - 小程序没有公开的可编程桌面组件 API；用户已确认无需。
   - 删除单事项/组合桌面、桌面直接操作、组件配置/帮助、相关 Plus 权益与测试。
   - Plus 范围调整为逐次明细、周累计、复盘长图、深度洞察、额外装扮（是否保留 Plus 待定）。

5. **移除旧程序迁移**
   - 不做 Android 备份导入、Loop `.db` 导入、schema12 双向兼容、跨端恢复测试。
   - 云端 schema 独立版本化；仍保留用户主动导出 JSON/CSV 和删除数据，作为数据访问/可携带性，不等同于旧程序迁移。
   - 是否提供导入待确认；v1 不承诺。

6. **验证边界**
   - 服务器只做 typecheck、Vitest、云函数本地测试/打包、构建、包体审计；不跑微信 IDE/真机/支付真实交易。
   - 真机/CloudBase/支付/订阅/审核必须在图形界面完成。
   - 不以“构建通过”代替云函数部署、权限规则、订阅真实发送或支付沙箱验收。

## 后果

- 工作量比本地优先方案增加约 25%：页面级数据流、云函数、事务、权限规则、支付/订阅、云端测试。
- 产品从“离线私密”转为“云端便利”；介绍、隐私政策、客服话术必须同步，不能继续写“100% 离线/数据只在设备”。
- 无网络时不可用；用户换微信账号无法访问原数据；需要导出/删除和账号说明。
- 个人虚拟支付可用但有类目、备案、月度限额和费率约束；iOS 可用但配置以后台为准。
- 一次性订阅无法替代 Android 本地提醒；必须接受“本次提醒”或改用系统日历混合。
- CloudBase 有免费体验期，之后计费；需在发布前估算读写量与成本。
- 无桌面组件、无旧数据迁移，产品介绍不得暗示这些能力。

## 未决

- Plus 是否 v1 收费；若不收费，Plus 功能全免费还是后置。
- 提醒：一次性/每日摘要/系统日历混合/不做，四选一。
- 是否保留 JSON/CSV 导出；是否提供导入（非旧程序迁移）。
- CloudBase 预算与套餐；是否接受个人主体月度限额。
- 小程序类目、备案主体资料、品牌/GPL/插画发布边界。
