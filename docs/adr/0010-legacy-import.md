# ADR 0010：FL18 旧习惯导入与 Android 离线迁移

2026-11-06。新增Loop数据库备份导入，Android数据方案为用户主动导出完整文件并在另一设备确认恢复，无云、账号或订阅。

- 仅支持已核定的Loop SQLite user_version 21–25、Habits/Repetitions格式。旧原生DayPanel可导出同结构习惯.db；不读取另一App私有库，不自动迁移旧扩展小事/场景。旧双库ZIP、CSV、未知版本、损坏库明确拒绝，原文件不修改。依据字段/枚举格式独立编写适配，不复制或翻译GPL算法、导入器或测试资源；来源见LEGACY-FORMAT。
- SAF选文件后限制8MiB，将字节放到本App唯一临时目录，以只读SQLite连接打开，无onUpgrade/源库写入。校验SQLite头、版本、quick_check、真实表/列、引用、唯一habit/day、日期和值、行数/文本上限，拒绝视图/触发器和非标准对象。读取结束关闭删除临时副本；失败/取消不修改业务库。大文件上限与现有备份一致，不宣称无限容量。
- 布尔原始2→1000完成、0→0明确未完成；1自动覆盖/-1未知不写完成，3跳过保留为关联手记。只读Repetitions，不导入派生Checkmarks/Scores/Streak。数值为整数千分位，0是实际记录，1/2/3都是0.001/0.002/0.003而非布尔标记；-1无数值。仅支持至少目标且正目标最多3位小数；至多目标整项标不支持，不反向解释或静默丢值。
- 时间戳必须为UTC午夜编码的日，按UTC年月日转本地日键，不按设备时区挪日；1900起至导入预览当天，未来/非午夜/重复/失联/非法值整文件拒绝。没有真实创建日则起始日取最早原始日期，无记录用导入日；明确是可用记录边界而非伪造创建时间。
- 原每天频率可保留；其余滚动n/d不自动当每周或间隔，用户必须在每个选中项确认导入后的安排（每天/自然周N日/间隔N日）。显示原频率/目标/单位及不可同义迁移说明。历史计划/归档履历未知，habit_activity仅从导入日建立基线，之前实际记录可看但不算失败/连续。旧目标变动不可重建，数量保留原数值、以导出时单位解释，明示限制。保留原名称/归档/顺序、描述/问题/原频率信息与记录备注；旧提醒不启用、旧配色/得分不照搬、导入不发成就卡或播放完成反馈。
- 支持选择部分可导入习惯追加。UUID经哈希命名空间化；无UUID的21–23库用原id/名称/类型哈希，来源说明其重命名去重局限。同ID已在本机则跳过且不覆盖、不合并记录；事务内再次检查冲突，避免预览后另一页面导入导致重写。用户编辑后再次导入仍不覆盖；已删除的导入项允许重新导入。
- 先生成不可变导入预览，保存时检查generation和预览日期；从当前一致快照合成追加结果，保留已有全部表，沿用单事务恢复协议保存导入前完整副本并写入合并结果、递增generation。中断全回滚，成功后提醒/组件同步；旧页面/组件失效。最近一次副本可回退，明确回退也会替换导入后的新改动。SQLite8/备份schema8不升级，新增来源说明作为已有notes数据被完整备份。
- UI在数据与备份新增明确的Loop导入入口，预览逐项选中/已存在/不支持、数量和原频率，必要安排选择、差异确认勾选，固定取消/导入。只确认后写入；取消保持旧库。追加不等于完整备份恢复，两个入口区分清楚。

回退页缓存副本同时缓存对应generation，另一页面恢复/导入后旧回退页不得以新generation提交旧副本。
