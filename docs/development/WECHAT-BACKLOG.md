## 顺序

1. **P0 确认**：Plus 是否收费；提醒一次性/每日摘要/系统日历/不做；是否保留导出/导入；CloudBase 预算；类目/备案。
2. **P1 基座**：WM01–WM05。先跑通“新建→完成→云端持久化→换设备可见”，不先堆页面。
3. **P2 免费核心**：WM06–WM14。每域补云函数单测/权限/失败路径；提醒必须先确认订阅限制。
4. **P3 Plus/分享**：WM15–WM17。支付先有服务端状态机/幂等，再写 UI；无资质则跳过收费。
5. **P4 发布**：WM18–WM22。外部审核等待单独记录，不混入开发完成。

## 工程约束

- 2C4G 服务器只跑 `pnpm typecheck`、`pnpm test`、云函数本地测试/打包、`uni build`、包体审计；串行、限量；不跑微信 IDE、模拟器、真实支付、CloudBase 控制台审核。
- 不提交 AppID/环境 ID/密钥/模板 ID 私密配置；不提交云函数环境变量。
- 不写本地业务文件；导出临时文件只用于用户主动分享，不作为数据源。
- 不伪造 Android 能力：无桌面组件、无后台本地通知、无长期订阅、无旧数据迁移。
- 每次代码变更：typecheck + 相关测试 + 构建 + 包体 + `git diff --check`；云函数部署/权限/真机项单独记录。

## 待确认后第一步

确认 Plus/提醒/导出/云预算后，从 WM01–WM05 开始；首个验收必须是云端真实持久化 + revision 冲突 + 断网错误，不接受假数据或本地兜底。
