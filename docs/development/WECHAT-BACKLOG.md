## 顺序

1. **P0 确认**：三通道默认时刻/授权引导；注销确认词与分批方案；广告后置表述；云端隐私定位；类目/备案。
2. **P1 基座**：WM01–WM05；先跑通云端真实持久化 + revision 冲突。
3. **P2 免费核心 + 三通道提醒**：WM06–WM16；每域补云函数单测/权限/失败路径；提醒必须逐通道验收。
4. **P3 分享/广告预留/注销**：WM17–WM20；AdSlot 只做开关，不接 SDK；注销必须真实分批删除，不接受假成功。
5. **P4 发布**：WM21–WM25；外部审核等待单独记录。
6. **后续广告**：WM26；v1 不接。

## 工程约束

- 2C4G 服务器只跑 typecheck、Vitest、云函数本地测试/打包、`uni build`、包体审计；串行、限量；不跑微信 IDE、模拟器、广告/真机/审核。
- 不提交 AppID/环境 ID/密钥/模板 ID 私密配置；不提交云函数环境变量。
- 不写本地业务文件；导出图片/分享临时文件不作为数据源。
- 不伪造能力：无桌面组件、无后台本地通知、无长期订阅、无旧数据迁移、无**整库**导出/客服副本；单条记录/习惯/手记删除仍保留；注销是唯一账号级删除入口。
- 广告 v1 不接：不加载广告 SDK、不请求广告、不在隐私指引声明广告数据；只保留开关/占位。
- 注销：个人设置入口 + 二次确认 + 确认词；云函数分批删除，全部成功才回首次引导；失败可重试，不假装成功。
- 每次代码变更：typecheck + 相关测试 + 构建 + 包体 + `git diff --check`；云函数部署/权限/真机项单独记录。
