# 微信小程序版（uni-app）设计总结 v3

2026-11-16。分支 `feat/wechat-miniprogram`，基线 `main` 24292a4。本文按用户最新决定修订：**数据上云、不存本地；个人主体；v1 全免费，后续广告；提醒采用一次性 + 每日摘要 + 系统日历三通道，默认全开；不做桌面组件；不迁移旧程序；不提供导出；个人设置提供注销账号**。

决策见 [ADR0019](../adr/0019-free-ads-reminders-no-export.md)；云优先与订阅限制见 [ADR0018](../adr/0018-cloud-first-wechat.md)；初始提议见 [ADR0017](../adr/0017-wechat-mini-program.md)。

## 0. 关键结论

### 0.1 v1 全免费，后续广告

- 删除 Plus、虚拟支付、订单、权益、iOS 商品、购买/恢复/退款状态；所有功能免费。
- v1 **不接广告**，只预留广告位组件和开关；先验证留存。
- 后续达到微信流量主条件（公开规则：累计独立访客 100 人及以上）后，再评估 Banner/插屏/激励/视频/原生模板/封面等形态；分成与可用形态以后台为准。
- 广告不得遮挡主操作、诱导点击、伪装内容或“看广告才能用核心功能”；接入前更新隐私指引，删除“零广告”宣传。
- 广告不是 v1 的验收项；v1 不能因为“以后有广告”而加入广告 SDK 或提前收集广告数据。

### 0.2 提醒三通道（默认全开）

- **一次性本次提醒**：用户点一次授权 → 一条消息 → 云函数到点发送；用完即止。
- **每日摘要续订**：用户当天授权下一条；云函数在设定时刻发送今日摘要；用户不打开/不续订就没有下一条。它仍是一次性订阅，不是长期订阅。
- **系统日历混合**：`wx.addPhoneRepeatCalendar`/`wx.addPhoneCalendar` 写系统日历副本，可重复/可闹钟；需 `scope.addPhoneCalendar`，系统确认；不能程序化更新/删除已写事件。
- 设置默认三通道全开；但“默认开”不等于“已授权”：摘要首次/每日要用户点授权，日历首次要系统授权，一次性每次要用户点订阅。
- 默认建议避免同一时刻重复：日历按习惯时刻、摘要固定 21:00、一次性只在用户主动订阅时创建；UI 显示三通道实际状态并允许单独关闭。
- 个人工具类不能申请长期订阅；三通道都不能承诺“每日必达”。UI 必须区分“已订阅本次/摘要已续订/日历已写入/已失效”，不能只写“提醒已开启”。

### 0.3 不提供导出，个人设置提供注销账号

- 按你的要求，v1 不做**整库导出 JSON/CSV**，不提供客服、邮箱或工单的数据副本/删除请求；账号级删除只通过“注销账号”完成。
- 这里的“删除”指**注销账号级**；单条记录、习惯、手记、小事的删除仍是核心功能，保留。这里的“导出”指整库数据导出；**成就卡/复盘海报的分享图片不算整库导出，保留**。
- 个人设置提供**“注销账号”**按钮：二次确认 + 输入确认词；注销会按 openid 删除全部云端业务数据和提醒任务，不可恢复；日历副本需用户自行在系统日历删除，已发送的订阅消息不可撤回。
- 注销云函数分批删除，全部成功后才回到首次引导；部分失败显示“注销未完成”并可重试，不能假装成功。
- 注销满足“删除”权利；**不提供副本仍存在个人信息可携带/复制权的合规风险**，按你的决定接受，并在隐私页说明“不提供数据副本”。
- 不提供客服/邮箱工单；隐私页说明数据在云端、保留期限、开发者可访问、非端到端加密，以及注销入口。

### 0.4 iOS

- 不需要单独注册 iOS 小程序；同一个 AppID 覆盖 iOS/Android。
- v1 无支付，所以不涉及 iOS 虚拟支付、Apple 15%、个人收款限额。
- 后续广告走微信流量主，iOS 同样展示；广告审核/隐私以后台为准。
- 如果未来恢复收费，再另写 ADR，不能把广告和付费混成未披露路径。

## 1. 目标与非目标

### 目标

- 微信小程序内完成 DayPanel 核心闭环：习惯（布尔/数量/次数）、频率与计划、休息、小事/常驻、手记、成就卡、统计、回顾、外观、提醒、分享。
- 云优先：CloudBase 数据库 + 云函数；不写本地业务数据；同一微信账号跨设备看到同一份数据。
- v1 全免费；三通道提醒默认全开、可用且诚实标注限制；后续广告可插拔；个人设置可注销。
- 视觉延续冷白、浅蓝、淡紫、暖橙、大圆角；适配小程序导航、胶囊、键盘、安全区、网络状态。

### 非目标（v1）

- 本地业务存储、离线写入、离线队列、本地数据库加密。
- Plus/付费、虚拟支付、订单/权益、Google Play 权益互通。
- 长期订阅消息、后台本地通知、精确闹钟、通知“稍后 10 分钟”。
- Android 桌面组件、组合桌面、桌面直接打卡。
- 旧 Android/Loop 迁移、schema12 兼容。
- 整库导出、客服/邮箱副本；只提供个人设置注销入口，不提供副本。
- 广告 SDK/广告位上线；v1 只预留开关。
- iOS 原生 App/Web/桌面端；iPad/PC 不做平板双栏验收。
- 24 MB Noto Serif SC 字体打包；v1 系统字体。

## 2. 云优先的硬约束

| 约束 | 影响 | 设计应对 |
|---|---|---|
| 小程序端查询默认/最多 20 条 | 不能一次拉全量 | 页面级查询 + 分页；云函数聚合 |
| 云函数查询默认 100 条 | 统计/清理要分批 | 云函数内部分页/聚合；返回摘要 |
| 小程序链路响应上限 1 MB | 不能把完整状态返回客户端 | 只返回当前页/摘要；大文件走云存储（仅分享/内部任务） |
| 云函数冷启动/网络延迟 | 每次写入有延迟 | busy/重试；函数瘦身；高频读客户端直读 DB |
| 无本地持久化 | 断网不可用 | 明确网络错误；不做假离线 |
| CloudBase 免费体验期后计费 | 个人成本 | 控制读写；发布前用价格计算器估算 |
| 广告需 100 UV 且审核 | 不能首发变现 | v1 不接；后续评估 |
| 小程序主包 2 MB/总包约 20 MB | UI/资源受限 | 分包、图标压缩、字体不进包 |

> 数据库单文档可较大，但小程序响应受 1 MB 限制；本设计不依赖“单文档塞全量状态”。

## 3. Google/微信能力替换矩阵（v3）

| 现有能力 | 微信替代 | 状态 | 设计与边界 |
|---|---|---|---|
| Google Play 分发 | 微信小程序平台 | 等价 | 同一 AppID 覆盖 iOS/Android；需主体、备案、类目、隐私指引 |
| Google Play 买断 | **v1 全免费；后续广告** | 改变 | 不做虚拟支付/Plus；广告需流量主+审核 |
| Play 购买恢复 | 无 | 移除 | 无付费、无权益 |
| Android 桌面组件 | 无 | 移除 | 用户已确认无需 |
| AlarmManager 本地提醒 | 订阅消息 + 系统日历 | 受限 | 一次性/每日摘要/日历三通道；无长期订阅、无必达 |
| 通知点击/稍后 | 订阅消息页面路径/日历 | 受限 | 可打开页面；无稍后、无回调 |
| SAF/系统分享 | 分享到微信/相册 | 受限 | 无整库导出；分享卡片/海报仍可 |
| SoundPool/触感 | `InnerAudioContext`/`wx.vibrateShort` | 受限 | 默认关闭；失败不撤回云端写入 |

| Loop/旧数据迁移 | 不做 | 移除 | 用户已确认无需 |
| 24 MB 字体 | 系统字体 | 受限 | v1 不打包 |
| 系统主题/语言 | darkmode + 自研 i18n | 等价偏受限 | 中英文案、日期格式自维护 |

## 4. 总体架构

### 4.1 形态

```text
DayPanel/
├── lib/, android/                 # 现有 Flutter，保持不动
├── miniprogram/
│   ├── src/
│   │   ├── pages/                 # 主包：today/tasks/journal/mine
│   │   ├── packages/              # 分包：habit/task/journal 详情/统计/卡片/设置
│   │   ├── components/            # 含 AdSlot（v1 不加载广告）
│   │   ├── stores/                # 页面级 Pinia
│   │   ├── domain/                # 纯 TS 规则
│   │   ├── data/                  # CloudBase 客户端封装/DTO
│   │   ├── platform/              # wx.cloud/wx.reminder/calendar/share/ads 适配
│   │   ├── i18n/ styles/ static/
│   │   └── pages.json/manifest.json
│   ├── cloud/
│   │   ├── functions/
│   │   │   ├── api/               # 读接口 + 写动作分发（含注销）
│   │   │   └── reminder/          # 一次性/摘要任务 + 定时发送
│   │   └── shared/                # 与客户端共享的纯领域规则
│   ├── tests/
│   └── scripts/
└── docs/
```

### 4.2 分层

- 页面只调用 `stores`；stores 调 `data`/云函数；不直接写数据库。
- `domain/` 纯 TS：日期、数量、频率、计划、休息、卡片、统计、洞察；客户端展示与云函数校验共用。
- `data/`：CloudBase 查询、云函数调用、DTO；**不写本地**。
- `cloud/functions`：权威写入、revision/事务、服务端聚合、提醒任务、注销批处理。
- `platform/`：`wx.cloud`、`wx.requestSubscribeMessage`、`wx.addPhoneCalendar`、`wx.showShareImageMenu`、`wx.vibrateShort`、未来 `ad` 组件；测试 mock。

### 4.3 不保留全量客户端状态

小程序单次查询 20 条、响应 1 MB；全量状态会随记录增长失效。页面按需加载，统计服务端算；跨设备写入用服务端 revision。代价是 UI 不能照搬 Flutter 全量内存模型。

## 5. 云端数据模型

### 5.1 集合

| 集合 | 粒度 | 说明 |
|---|---|---|
| `dp_meta` | 每用户 1 条 | schema、revision、generation、时间；并发基准 |
| `dp_profile` | 每用户 1 条 | 习惯（含 plans）、分组、设置、外观、提醒偏好；目标 <600 KB |
| `dp_days` | 每用户每天 1 条 | `{day, entries:{habitId:value}}` |
| `dp_tasks` | 每任务 1 条 | 一次性/常驻、计划/完成、归档 |
| `dp_task_days` | 每用户每天 1 条 | 常驻按日完成 |
| `dp_notes` | 每手记 1 条 | 日期、正文、关联；分页/搜索 |
| `dp_cards` | 每天 1 条 | 成就卡、收藏、心得、快照 |
| `dp_activity` | 每习惯每天 1 条 | 归档履历 |
| `dp_breaks` | 每段休息 1 条 | 暂停/休假/跳过 |
| `dp_events` | 每事件 1 条 | 逐次明细；分页/统计 |
| `dp_jobs` | 每提醒任务 1 条 | `kind: once|digest`、sendAt、status、payload |

无 `dp_orders`/`dp_entitlements`/`dp_deletion_requests`：v1 无支付、无客服工单；注销走个人设置。

权限：客户端仅创建者可读，禁止客户端写；云函数从 `OPENID` 取身份，不接受客户端传入 openid。索引：`_openid`、`_openid+day`、`_openid+habitId+day`、`_openid+status+sendAt`、`_openid+createdAt`。

### 5.2 读取

| 接口 | 返回 |
|---|---|
| `api.today(day)` | profile + 该日 days + 当日 tasks/task_days/card + 提醒偏好 |
| `api.month(month)` | 该月 days/cards + 手记分页 |
| `api.tasks(filter)` | 任务分页 |
| `api.journal(query, cursor)` | 手记分页/计数 |
| `api.stats(range, habitId)` | 完成率/连续/数量/年历摘要（服务端聚合） |
| `api.insights(range)` | 30/90/365、星期、趋势、共现、月度 |
| `api.cards(month)` | 卡片分页/详情 |
| `api.reminderStatus()` | 近期任务状态、摘要续订状态、日历提示 |

不做“启动全量拉取”；断网显示错误/重试，不显示假数据。

### 5.3 写入

统一 `api.mutate(action, payload, expectedRevision)`：

1. 取 `OPENID`；读 `dp_meta`；校验 revision。
2. 事务读所需文档（profile/day/card 等）。
3. 执行同源领域规则。
4. 写受影响文档；`revision+1`；删除/重建时 `generation+1`。
5. 返回 `{ok, revision, changed}`。

动作：`saveHabit`、`archiveHabit`、`deleteHabit`、`recordHabit`、`clearRecord`、`saveTask`、`completeTask`、`saveResidentRecord`、`saveNote`、`deleteNote`、`saveReminderPrefs`、`favoriteCard`、`saveReflection`、`saveBreak`、`deleteBreak`、`saveEvent`、`deleteEvent`、`deleteAccount`。

删除习惯/注销账号批量清理：云函数分页删除 days/events/activity/profile/jobs 等；先隐藏/归档再清理，失败可重试。`deleteAccount` 是高风险动作，必须先递增 `generation`/写入 `deleting` 状态，再分批删除，最后清空业务集合或保留最小 tombstone；旧页面/旧 token 的写入必须被拒绝。全部删除成功后才返回完成。

### 5.4 并发/一致性

- 每次写带 `expectedRevision`；不匹配返回 `conflict`，客户端刷新后重试。
- 云函数事务只覆盖少量文档；大删除/注销分批。
- 注销先写 `deleting` 状态并递增 `generation`，再分批删除；部分失败保持 `deleting`，客户端只能重试/继续注销，不能回到正常使用；完成后清空业务集合或保留最小 tombstone。
- `generation` 防旧页面写入；客户端不跨会话缓存业务数据。
- 云端时间用服务端；业务日期仍用用户本地日历日，服务端只校验格式/范围。

### 5.5 成本/保留

- 页面级查询、服务端聚合、分页；避免启动全量。
- 免费体验期后按套餐/资源点计费；发布前用价格计算器估算。
- 数据保留：不提供整库导出/副本；个人设置提供注销账号，按 openid 删除云端业务数据和提醒任务；隐私页注明云端存储、保留期限、开发者可访问、非端到端加密、注销入口。
- 不提供副本仍有个人信息可携带/复制权的合规风险，按负责人决定接受，不在文案中承诺“可下载副本”。
- 不做 E2E；若未来要做，需重新设计查询/统计。

## 6. 提醒：三通道

### 6.1 一次性本次提醒

```text
用户点“订阅本次提醒”
  → wx.requestSubscribeMessage({tmplIds:[T]})
  → accept → api.createReminderJob(kind='once', sendAt, data, page)
  → dp_jobs pending
  → 定时云函数到点 subscribeMessage.send
  → sent / invalid / failed
```

- 一次授权一条；用完即止；UI 显示“本次已订阅/已发送/已失效”。
- 适合临时提醒；不能承诺每日。

### 6.2 每日摘要续订

```text
用户点“订阅今日摘要”
  → requestSubscribeMessage(摘要模板)
  → accept → api.createReminderJob(kind='digest', sendAt=今日摘要时刻, ...)
  → 到点发送“今日待打卡摘要”
  → 次日需要再次授权
```

- 用户不打开/不续订 → 下一条没有额度；不是长期订阅。
- 摘要只发一条，聚合多个习惯，避免每条习惯一次授权。
- 默认时刻可配置；静默时段不发送；可关闭摘要。
- UI 显示“今日摘要已续订/未续订/已发送/额度已用完”。
- 若用户希望“每天固定”，必须说明“需要每天打开续订”，不能写“自动每日提醒”。

### 6.3 系统日历混合

- `wx.addPhoneCalendar`（单次）/`wx.addPhoneRepeatCalendar`（重复）；需 `scope.addPhoneCalendar`，系统确认。
- 固定每天：每天重复；固定星期：每个选中星期一个每周重复事件；每 N 天/弹性周目标：只写单次下一次，不伪造 RRULE。
- 日历是独立副本：修改提醒要重新写入；旧事件需用户去系统日历删除；不能程序化更新/删除。
- 设备本地状态，不存云端；换机后需重写；文案明确“本机日历副本”。
- 厂商日历提醒差异/权限拒绝要捕获并给出可理解提示；不把“写入失败”显示为“已提醒”。

### 6.4 通道关系与默认值

- 三通道默认全开；但默认开不是默认已授权：
  - 日历首次需要系统授权；摘要首次/每日需要用户点订阅；一次性每次需要用户点订阅。
  - 未授权时显示“已开启，待授权”，不显示“已提醒”。
- 为避免同一时刻重复：
  - 日历按习惯设置的时刻写入；
  - 摘要默认 21:00 发一条今日汇总；
  - 一次性只在用户主动点“订阅本次”时创建，不默认排程。
- 同时开启仍可能重复，提醒中心必须显示每个通道的下一次时间/状态，并允许单独关闭；建议用户按需要关闭重复通道。
- 新用户默认三开；首次进入提醒中心时引导授权，避免在启动时连续弹窗。
- 提醒设置页集中展示三通道状态、授权状态、下一次时间、失效原因。

## 7. 广告（后续，v1 不接）

- v1 只预留 `AdSlot` 组件和远程开关；不加载广告 SDK、不请求广告、不在隐私指引声明广告数据。
- 后续达到流量主条件（公开规则 100 UV）后，评估 Banner/插屏/激励/视频/原生模板/封面；分成/形态以后台为准。
- 广告位置：非核心路径（我的/统计底部/复盘结果页等）；不在记录确认、删除、隐私、提醒授权弹窗中插屏；不遮挡主按钮；不诱导点击；不“看广告解锁核心功能”。
- 广告上线前：更新隐私指引、用户告知、广告标识；重新审核；监控投诉/误触。
- 广告收入不改变“功能免费”；若未来加付费，另写 ADR，避免“广告+付费”双重收割。
- 移除所有“零广告”宣传；品牌介绍改为“免费使用，后续以广告支持”。

## 8. 功能范围与分期

### P1 云基座与首个纵切（7–10 人日）

- 习惯 CRUD/三种记录/历史纠正/频率/休息/分组/排序。

- 网络错误/空态/重试/冲突提示。
- 三通道提醒：一次性/摘要/日历；`dp_jobs` + 定时云函数；状态文案。

### P3 分享与广告预留（5–7 人日）

- 复盘长图、深度洞察等原高级能力全部免费；无锁定态。
- 隐私页：云端说明、数据保留、注销账号入口；不提供客服/邮箱副本。

### P4 硬化与发布（7–10 人日）

- 云函数异常/超时/幂等/限流/批量删除；日志/告警。

- 隐私指引/API 声明/备案/类目；体验版/真机/审核。

## 9. 页面与交互

### 9.1 页面地图

主包四 tab：

- `pages/today/index`：日期条、今日习惯、周目标、休息、计划外、卡片、提醒状态入口。
- `pages/tasks/index`：一次性/常驻/历史。
- `pages/journal/index`：月份/筛选/搜索/写手记。
- `pages/mine/index`：习惯、外观、提醒中心、卡片、统计、洞察、复盘、隐私与帮助（注销账号）。

分包：

- `packages/habit`：详情/编辑/管理/排序/休息/日志/单习惯统计/计划历史。
- `packages/task`：详情/历史/日期纠正。
- `packages/journal`：编辑/日期/关联。
- `packages/review`：统计/年历/时间线/单日/卡片册/详情/复盘。
- `packages/settings`：外观/提醒中心/隐私/帮助/注销账号/网络诊断。
- `packages/onboarding`：首次说明（云端、隐私、提醒限制、免费+后续广告）。

### 9.2 云优先交互

- 首屏先壳后数据；skeleton；不显示假数据。
- 断网：错误 + 重试；内存中上次展示可保留，但不允许写入。
- 写入：busy/防重复；成功后再更新；失败保留输入并提示重试。
- 跨设备：`onShow`/下拉刷新；冲突提示刷新。
- 提醒：三通道状态分开显示；授权拒绝/额度用完/日历写入失败均有明确文案。
- 隐私：说明数据在云、开发者可访问、非 E2E；个人设置提供注销账号；不提供副本/客服；注销前提示日历副本需自行删除。

### 9.3 UI 约束

- 原生 tabBar/导航栏，避开胶囊；页面栈 ≤10；`switchTab` 不传 query。
- 键盘避让/安全区/底部面板；`page-container` 或自定义 overlay。
- 暗色 `darkmode`/`theme.json` + `wx.onThemeChange`；320 px/1.6 倍/48 px 点击区/aria。
- 列表分页/骨架/空态；365 格热力图 flex 行列。
- 视觉冷白/纸白/蓝/紫/橙/青、24 px 圆角、细边轻阴影；字体不进包。

## 10. 非功能设计

### 10.1 隐私/安全/合规

- 数据在 CloudBase（腾讯云）；开发者可访问；非端到端加密；隐私指引如实说明。
- 身份仅 openid；不取头像/昵称/手机号；按 openid 隔离。
- 客户端读“仅创建者”，写关闭；云函数校验 OPENID。
- 无广告 SDK v1；后续广告接入前更新隐私指引并重新审核。
- 注销：个人设置 → 注销账号 → 二次确认 + 输入确认词 → 云函数分批删除 → 成功回首次引导；失败显示未完成并可重试。
- 注销满足删除权；不提供整库副本仍有个人信息可携带/复制权风险，按负责人决定接受并在隐私页说明。
- 不做广告/分析 SDK 之外的追踪；不把用户文本用于训练；不做公开社区。

### 10.2 性能/成本

- 页面级查询/分页/服务端聚合；避免启动全量。
- 云函数瘦身、共享依赖、按需拆分；冷启动/写入 busy。
- 监控错误率/P95/DB 读写/提醒失败/注销进度；发布前估算成本。
- 包体主包 ≤1.6 MB 目标/2 MB 硬限；图标压缩；字体不进包；统计/设置分包。
- 2C4G 服务器只跑 typecheck/测试/构建/包体；不跑 IDE/真机/云控制台。

### 10.3 i18n/日期

- 端口 734 个 ARB key；脚本检查中英一致。
- 日期本地日历日 `YYYY-MM-DD`；服务端只校验；自研星期/月格式。
- 数量整数千分位、最多 3 位小数；拒绝负数/科学计数/超长。
- 文案去掉“离线/本地/桌面组件/系统通知/长期提醒”，改为“云端/一次性通知/摘要续订/日历副本”。

### 10.4 可测试性

- 领域纯函数 + 固定时钟/ID；客户端/云函数共享夹具。
- 云函数单测 mock 数据库/事务：revision 冲突、发卡、删除、提醒状态、注销批处理。
- 权限规则测试：不能读他人/不能客户端写。
- 组件测试：表单/空态/网络错误/授权拒绝/三通道状态。
- 真机：弱网/断网/跨设备/日历/订阅/相册/分享/广告预留（不加载）。

## 12. 风险与待确认

| 风险/决策 | 影响 | 建议 |
|---|---|---|
| 全免费无收入 | 云成本自担 | 控制读写；广告后置；监控成本 |
| 广告需 100 UV/审核 | 短期无法变现 | v1 不接；达到条件再评估 |
| 广告与原“零广告”品牌冲突 | 用户信任/审核 | 更新介绍；广告不遮挡核心；不诱导 |
| 三通道默认全开 | 授权弹窗/重复提醒 | 默认建议日历按习惯时刻、摘要 21:00、一次性按需；提醒中心显示状态并允许关闭 |
| 一次性/摘要不能必达 | 投诉 | 文案明确；不写“自动每日”；摘要需每天续订 |
| 系统日历不可更新/删除 | 旧事件残留 | “副本”说明；重新写入指引；注销提示日历需自行删除 |
| 不提供整库导出/副本 | 可携带权/信任 | 个人设置注销满足删除；不承诺副本；隐私页说明风险 |
| 注销批处理失败 | 数据残留/误以为成功 | 分批+进度；全部成功才完成；失败可重试 |
| 云端数据/开发者可访问 | 隐私定位变化 | 隐私指引如实说明；非 E2E |
| 断网不可用 | 弱网体验 | 错误/重试；不做假离线 |
| CloudBase 成本 | 免费期后费用 | 发布前估算；控制查询 |
| 1 MB/20 条限制 | 大历史/分页 | 页面级/聚合；不返回全量 |
| 微信审核/备案 | 上线时间 | 预留 2–4 周 |
| 品牌/GPL/插画 | 发布许可 | 发布前审查 |

需要负责人确认：

1. 三通道默认时刻：日历按习惯时刻、摘要 21:00、一次性按需，是否接受？是否允许用户单独关闭通道？
2. 注销账号的二次确认方式：输入“注销”确认词 + 不可恢复提示，是否足够？
3. 不提供整库副本的合规风险是否接受；隐私页写明“不提供副本”即可。
4. 广告后置：达到 100 UV 后接哪些形态/位置；是否接受“免费+广告”的新品牌表述。
5. 云端数据/断网不可用/开发者可访问的隐私定位是否接受。
6. 类目/备案主体资料、小程序名称/品牌/GPL/插画边界。
