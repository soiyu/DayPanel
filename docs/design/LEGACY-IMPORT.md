# FL18 旧习惯导入与离线迁移

数据与备份保持蓝色完整导出、淡紫恢复，并增加独立Loop导入卡片。导入流程沿用SoftPanel/SheetFrame/AppAction和现有主题/字体，中英明暗/窄屏/大字号/键盘可达。

选Loop备份.db → 只读检查 → 逐项预览名称/类型/归档/记录数量/原频率/目标 → 选要追加的内容 → 非每日频率明确选择新安排 → 阅读差异并勾选确认 → 导入 → 显示成功和回退入口。

预览默认选择支持且未存在的项；已存在只标记、不覆盖；不支持的至多目标等可看到原因，但不能选。重复文件全部已存在时没有可提交动作。坏文件不会进入部分写入。日期变化/恢复后的旧预览拒绝，重新选文件。

导入页明示不导入旧提醒、派生自动完成、得分和旧扩展小事/场景；跳过与备注保留为关联手记，旧计划/归档未知，过去不算失败。原滚动频率没有默认猜测，逐项用户决定今后的日程。已有数据保留，最近副本为导入前完整状态，回退将替换后续新改动。

离线换机说明在数据页可见：旧设备导出完整DayPanel JSON → 自行通过USB/本地文件方式传输 → 新设备选择恢复并检查预览 → 设置该设备通知权限与桌面组件。备份不加密，文件位置由系统文件选择器决定，卸载会删除本机库和恢复副本，导出文件保存在App之外。这里不承诺云同步或自动备份。
