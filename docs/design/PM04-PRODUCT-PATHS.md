# PM04 产品路径修复流程

依据ADR0015，将PM02/03已确认问题落地。本批已实施并完成限定工程/API28验收，完整证据和未测范围见STATUS。

- 新建：目录或搜索 → 可编辑草稿 → 选择完成/数量/次数 → 确认目标与安排 → 保存 → 新项今日概览 → 实际记录；返回保留原筛选。
- 完成：点明确完成，状态更新；撤销是明确清除，重复请求不翻转。
- 数量/次数：选修改总量或记入本次 → 填值 → 显示保存后的合计 → 确认 → 事务校验版本并写；已变化则重新打开，取消不落库。
- 计划外：日常的记录其他习惯 → 选择合法活跃项 → 所选日期记录；不改计划，不伪造必做。
- 历史：日期 → 当天详情/休息事实 → 围绕该日的历史 → 同范围统计；回最近需主动选择。
- 搜索：本月关键词 → 无结果 → 保留词与习惯条件，扩展全部月份 → 原文。
- 常驻：今天/逾期之后就能找到；一天最多一次，未做不欠账。
- 备份：导出 → 系统位置 → 写入成功 → 本机导出日期；恢复预览确认 → 成功 → 回日常/按需检查提醒和桌面。
- 桌面：选择习惯或小事 → 系统确认 → 成功回调绑定真实实例；取消不生效。原Launcher长按添加/重配流程保留。

按量测试同时使用阅读页数、距离小数、分钟；按次使用整数次数；完成、一次性、常驻分别检查。只提供已实现的记录和统计，没有逐次事件历史或周累计量时不作相应承诺。
