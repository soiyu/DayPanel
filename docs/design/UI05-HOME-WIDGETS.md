# UI05 桌面组件视觉重排

2026-11-08，用户反馈桌面组件丑。基线187a06c。仅Android RemoteViews视觉/尺寸适配，不改数据模型、配置绑定或动作事务。

## 方向

冷白或深蓝中性卡面，22dp圆角细边；标题与状态优先，小图标和短日期负责识别；数量/次数突出真实值，目标和单位降低字重，实际比例画细进度。次数与数量都只展示已有真实值，微小比例不设最小假进度。达标用平静青绿色，不把整张卡换成主题色。任务使用独立清单小图，保留一次性/常驻语义，不画虚假完成百分比。

设置和详情采用20dp线性图形，48dp透明点击区域，替换大块紫底字体符号。主动作只留一处强强调，达标后改柔和底；整块状态/标题也仍可直接操作。默认日计划重复说明可隐藏，周目标/休息/归档/任务类型按空间显示，完整语义始终可读。

## 尺寸

默认建议3×2，最低高度180降至140dp、最窄128dp；Launcher实际格子数依平台。窄于200dp、高度低于190dp或大字号采用紧凑布局：减少装饰、单行短日期、真实状态和48dp操作区。标准布局使用40dp图标、名称和日期同一行层级，状态居中相邻，底部操作清楚；不再让图标独占一大行。

长名称可视觉省略，完整名称/ISO日期/数值/状态保留到可访问性描述；字号跟随系统。小尺寸适配不能通过缩小点击区完成。进度仅限活跃且非休息的数值或周达标日目标，显示0到100%的真实比例，超额数值仍如实显示。

## 边界与验收

完成/撤销保持显式目标，generation/revision/ABA、不同实例身份保持；数量/次数仍直接进入输入确认，设置和详情仍独立。SQLite11/schema11不变，无新增权限，不修改Flutter页面和旧原生工程。

测试需覆盖中英、明暗、1.0/1.6字号与紧凑/宽/大尺寸的实际测量、至少48dp点击区、状态和进度、对象失效空态、独立配置/详情。API28真实Launcher添加/缩放/完成取消/数量输入/多实例截图与工程测试分开记录，最终证据见STATUS。

任务主行使用“今天未记录/今天已做”或“待处理/已完成”，类型与完成日期移到次级说明；完整事实仍在语义中，避免英文重复Resident占据整块状态区。实际尺寸和字号验证由原生RemoteViews测量测试与真实Launcher分别记录。

最终适配补充：Launcher可能在系统字号变化时直接重建旧RemoteViews，未先触发新渲染。头部日期/名称、状态与主按钮因此使用限定空间内自动适配字号；状态采用剩余空间，辅助说明单行，不挤压按钮。专门测试“100%字号生成→160%字号直接重建同一视图”，并在实际设备确认文字不再纵向裁切。完整内容保留语义，长名称可省略。
