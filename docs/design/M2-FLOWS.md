# M2 数据保护与习惯整理

2026-11-05。沿用蓝/淡紫/暖橙、白色渐层、柔和阴影与统一底部面板。

- 我的增加「数据与备份」，详情首屏解释包含哪些数据。蓝色主操作导出、淡紫次操作选文件恢复；文件通过系统 SAF 选择。恢复前用真实条数预览，并明确“替换所有数据，不合并”。确认后保存恢复前副本，暖橙回退卡说明后续新增也会被替换。
- 日常提供情境/分组筛选。过滤条件有可见标签、应用/清除动作，空结果可解除筛选；概览仍为全局每日计划数量。每周目标独立区展示已达标天数和目标，不变成每日欠账。
- 编辑习惯将安排方式、目标、时段与分组在一个表单内组织；星期/间隔/周目标只展开相关字段。已有习惯明确写明改动明天生效；保存后详情显示待生效状态和历史版本。
- 管理习惯提供分组管理与排序。分组重名/空名就地提示，删除只解除所属关系。排序有拖动手柄与上下按钮，改变后明确保存；没有凭空新增习惯或自动重生任务。
- 所有新文案提供英文/简中。表单/预览支持滚动，操作固定底部，恢复中禁止退出，不把文件取消当失败。

规则权威见 ADR 0002。该批不新增提醒、专注、会员或云同步。
