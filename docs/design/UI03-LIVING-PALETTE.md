# UI03：生活图标与组合配色

先把内容和视觉关联起来，再安排页面颜色。新增流程为：常用事项目录（两列、物件插画、名称、真实默认目标）→可编辑草稿→保存。自定义入口始终可达，返回/取消不创建。详情/列表/装扮选择/桌面显示同一图标。

图标用柔和体积与高光、两到三种物件本色，保留可读轮廓：蓝色玻璃水杯、珊瑚书封和奶白书页、青绿鞋与橙色鞋带。图标ID原含义不变；固定本色让用户凭形状和颜色认事项。

三组主题：晴日书桌（冷白#F7F8FC、钴蓝#2459CC、鸢尾#7956B4、杏橙#A65B2B、松绿#247365），林间晨光（雾白#F4F7F5、深青#226B62、灰紫#75629B、陶橙#A15C37、湖蓝#366BA3），暮色花园（浅灰紫#F8F6FA、靛紫#6650A2、玫瑰#99566D、蜂蜜#946128、青绿#347568）。深色分别采用墨蓝/墨绿/墨紫中性底，不给正文蒙主色。布局中大面积留白、小面积色块；主动作明确、内容卡克制、日期暖色、回顾紫色；导航各栏目有自己的选中色。

正文14–16、条目17、标题22–28；左对齐、20页边距、12项间距。主题预览显示组合色条和多事项示例（注明预览），不只显示一个主色色点。先检视24图标总览，再看真实设备的目录、表单、首页、三个主题与深色；中英320dp/160%、取消/保存、名称匹配手选保护、原数据保留都验证。

设备复核补充：原快速填写1500毫升按四分之一得375毫升，不符合日常使用习惯，改为250/500/1000/1500等常用总量；阅读用1/5/10页。选项仍明确为当日总量，点选/取消不写，保存才更新。深色插画投影降低透明度，保留物件本色。
