# Luminous Focus 视觉延续 / 小日常功能结构

视觉来自负责人已选 Stitch 方向，名字仅为设计稿名称，本产品不提供专注功能。

当前精修色板：画布 #F6F8FE，文字 #18223B，次文字 #637089，操作蓝 #1656DF；蓝/紫/橙有各自浅底与深色映射。标题 28/22、条目 17、辅助 14/12；系统无衬线与中文 fallback，无网络字体。用途与细节见 [UI 精修](UI-POLISH.md)。

页面左对齐，20px 页边距，按层级采用 12/16/20/24px 模块间距。表面通常 24px 圆角、按钮 18px，浮动导航 26px。白色渐层/细边/柔和阴影构成轻盈玻璃感，模糊仅用于导航。主列表各自保存滚动位置。

导航：日常（日期与习惯）/小事（任务分组）/手记（文本日志）/我的（设置与管理）。日常使用安静的进度提示和清楚的真实行动行。空态引导添加自己的内容，默认不造“喝水已完成”等演示事实。

数量面板区分已记录值和编辑总量，四档目标比例只预填输入框，保存成功才确认；任务完成与重开有明确动词；归档保留历史，删除二次确认。表单、更多操作、删除确认和语言/主题选择都采用统一底部面板，底部按钮固定、表单头部随内容滚动。初期缺少的组件、成就卡、同步不出现假按钮。

48dp 触控，布局支持320dp和大字号；表单滚动避让键盘；中英文、明暗和减少动画继承系统规则。字体和颜色不能是状态的唯一线索。参考稿中的假通知、假比例和 Start Focus Flow 已排除。
