# Luminous Focus 视觉延续 / 小日常功能结构

视觉来自负责人已选 Stitch 方向，名字仅为设计稿名称，本产品不提供专注功能。

画布 #F5F8FC，文字 #191F33，次文字 #5F6B8A，操作蓝 #0D50D5，淡紫 #EDE9FF，逾期暖橙 #FFF0E1。标题 28，分区 20，条目 16，辅助 13–14；系统无衬线与中文 fallback，无网络字体。

页面左对齐，20px 页边距、16px 模块间距。概览 28px、条目 18px 圆角。白色表层/细边/柔和阴影构成轻盈玻璃感，长列表不做全屏模糊。

导航：日常（日期与习惯）/小事（任务分组）/手记（文本日志）/我的（设置与管理）。日常使用安静的进度提示和清楚的真实行动行。空态引导添加自己的内容，默认不造“喝水已完成”等演示事实。

数量打开不写入；保存成功才确认；任务完成与重开有明确动词；归档保留历史，删除二次确认。初期缺少的组件、成就卡、同步不出现假按钮。

48dp 触控，布局支持320dp和大字号；表单滚动避让键盘；中英文、明暗和减少动画继承系统规则。字体和颜色不能是状态的唯一线索。参考稿中的假通知、假比例和 Start Focus Flow 已排除。
