# 桌面直接操作

卡片主体和主按钮作用一致：布尔/小事未完成时“完成”，完成时“取消完成”或一次性“重新待办”；点击保持Launcher可见，只刷新真实状态。底部另设48dp详情入口；右上仍为配置。处理中显示“正在保存”，过期动作刷新真实状态，可再次操作，失败明确可重试。

数量点主体/输入总量直接打开输入界面，展示名称、日期、真实当前值、单位、目标与可选总量，保存后返回桌面。数量入口有独立承载Activity，旧详情不会拦住输入；配置也独立。休息/归档仅查看和管理，不提供虚假完成。

真实设备分别验证：App进程退出、Launcher完成/取消、快速重复、多实例、ABA旧动作、恢复旧请求、数量取消/保存、旧详情仍在后台时数量/配置、提醒和卡片联动。保留主用户库，只用临时Android用户写记录。
