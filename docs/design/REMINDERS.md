# FL11 提醒交互

2026-11-06。沿用暖橙时间、蓝色主操作、淡紫设置的视觉语义。

- 我的→提醒中心统一解释系统通知/精确权限状态，分别提供“允许通知”“系统通知设置”“设置准时提醒”。权限状态来自 Android，不用开关位置代替授权结果。
- 单习惯详情→习惯提醒；启停开关、时刻卡片（最多5个）、增加/移除、固定底部保存/取消。时刻选择器统一背景/表盘/选中圆角，可切换输入模式。
- 用户主动保存开启提醒后才申请通知权限。拒绝仍保存时刻，并提示配置暂未生效；不循环弹系统权限框。
- 归档习惯显示提醒暂停；中心列出保存配置而不掩盖归档状态。每日达标/周目标达标停止该周期的提醒。
- 通知显示习惯标题，可去记录或稍后10分钟。去记录打开真实详情/数量面板，打开不写入；稍后不跨日、重复动作不累加。
- 标准模式明确可能被节电延迟；声音/振动交给系统频道。新装设备的权限不从备份继承。
- 完整规则与系统边界见 ADR 0003。用户这轮明确完成后不关机。

2026-11-07 FL19设备补测：提醒启用行改为整行可点的具名开关，点击文字与右侧开关行为一致；未保存前不请求权限，取消不写入。拒绝系统通知仍保存时刻并提示受阻；原生回归若通知权限未正确授予会明确失败，不再静默跳过。
