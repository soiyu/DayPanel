# FL14 成就卡与完成反馈

2026-11-06，规则见 [ADR0006](../adr/0006-achievement-cards.md)。沿用既定冷白、蓝色动作、淡紫回顾和暖橙收藏。字体、圆角、字段和底部编辑区使用现有theme/components，不引入默认系统卡片列表或远程图片。

日常仍以记录为先，卡片区域放在清单后；不遮挡打卡或新增流程。今天没有卡时说明解锁条件，满足条件才显示真实领取动作；已获得则提供查看。过去未获得的日期不放空领取入口，未来不发卡。

六款卡面分别为晨光、植物与根、河流、阶梯、窗与书、星群。全部由本仓库CustomPainter独立绘制；蓝/紫构成空间，暖橙表示光。它们按日期轮换，非随机稀有卡。深色使用单独背景与线条对比。无计时、专注或付费资源。

收藏为明确目标值。翻面只改变视图；心得的取消、关闭或系统返回不写入，保存空内容清除原心得，按钮固定在键盘上方。长文字可滚动，读屏有文字名称，不依赖插画或声音表达状态。系统减少动画时，卡片翻面和习惯完成态切换无动画。

完成声音/触感采用独立开关、当前状态和系统限制说明，默认关闭。反馈仅随当天实际达标转换触发，打开卡片/重启/恢复不播放。声音为原创0.22秒双音PCM，通过脚本可复现；原生播放遵守静音、勿扰和系统音量，触感遵守系统设置。

## 验证

覆盖所有六款插画、中英×明暗320dp/160%、心得键盘280dp、真实收藏筛选、空态、翻面减少动画、编辑保存/清空/取消/返回及恢复后旧编辑拒绝。设备截图与实际验收范围记录在STATUS，不把模拟器反馈调用当作实机声学/触感质量验证。

RT01补充说明入口：卡片册右上“成就卡说明”列出一点晨光、慢慢生根、自有去处、向前一步、窗边有光、点点成星的实际卡面预览，明确按日期循环、同一解锁规则、不是等级或分享奖励。说明每天至少一项适用日习惯且全部达标才获得；收藏/心得是独立用途，PNG保存与系统分享可选，习惯名称和心得默认隐藏，分享摘录不改原文。预览不持有业务控制器，不生成卡或改变解锁证据。
