# 已有功能 UI 精修

2026-11-05。负责人认为主色正确，但单一、缺少细节，默认控件感明显。本轮直接重做现有 UI 的组件与状态，不新增收费、专注或演示数据。

## 设计取向

延续已选 Stitch 的冷白、蓝、淡紫与少量暖橙。蓝用于主操作和数量记录，紫用于手记/回顾，暖橙用于日期/情境和逾期；彩色底要浅，文字和操作保持清楚。页面底色由冷白过渡至轻紫，白色内容面板保留高可读性。只在主摘要、空态小插画和导航呈现明显层次，其余列表保持安静。

色板：canvas #F6F8FE；ink #18223B；blue #1656DF；lavender #8062D6；peach #D87A3D；muted #637089。深色采用独立底色/文字对比，不能把浅色透明卡直接压暗。

字体用已存在的系统字族，28/22/17/14/12 的层级和不同字重；压缩营销式大标题，日期和条目先出现。标准间距 4/8/12/16/20/24，按钮 48dp 起，卡片 20–28 圆角。

```text
页面标题                         回顾  新增
简短副标题
日期选择 / 星期条
轻渐层概览（真实数量 + 小型进度）
分区标题                         数量
彩色图标  条目标题 / 单位          操作
……
浮动圆角导航：日常 小事 手记 我的
```

## 具体修改

- 日常：紧凑星期条、今日圆点、真实状态摘要；按习惯图标分配蓝/紫/橙容器；完成态、数量条、记录按钮各有定义。
- 小事：轻量未完成/完成摘要，逾期暖橙日期标签，圆形完成动作，正文编辑和更多操作分开。
- 手记：紫色页眉、日期纸签与纸张式内容，空态使用原创 Flutter 几何图形；不造随机笔记。
- 我的：成组设置面板、独立彩色图标、当前值与箭头；主题/语言采用带选中反馈的选择面板。
- 习惯编辑：带图标的标题、清晰字段标签、两种记录方式的选项卡、七日圆角按钮、彩色图标选择；取消/保存固定在表单外的底部动作区。
- 数量记录：独立底部面板、实际当前值、目标、输入框、四档目标比例预填；只有保存写入，清除与取消清晰分离。
- 日期选择/删除确认：使用统一表面、圆角、字体与动作；保留日期选择器可访问性及输入能力。
- 管理/详情/回顾：同一套条目、日期标签、分段统计；七天柱图辅以每一天的真实数字，不能将比值当实际完成率。
