# FL17 外观与习惯装扮

冷白#F6F8FE、文字#18223B、主蓝#1656DF、记录紫#7252BE、日期橙#A95824延续已选方向。可选林间青与暮色紫有独立浅/深映射，主操作白字对比度达到4.5:1。字体为系统无衬线或本地Noto Serif SC，按钮仍48dp起，不压缩系统文字缩放。

```text
我的 → 外观
真实内容预览 / 明确标记的排版样张
明暗   跟随系统 / 浅色 / 深色
主题   晴空蓝 / 林间青 / 暮色紫
字体   系统 / 书页体
图标边框   柔和底 / 圆环 / 无边框
恢复默认（仅改变预览）
取消                       保存

习惯编辑 → 图标与装扮
所选图标、名称预览
图标网格（24种，有文字名称和选中语义）
配色（自动及五种预设）
边框（跟随默认及三种选择）
原有取消 / 保存
```

外观预览使用现有SoftPanel、AppAction和主题。操作区固定、内容滚动，选项换行，保存前全App和桌面不提前改色；保存成功才刷新。习惯装扮与业务字段同一次保存，不影响明天生效的计划版本。颜色不承担唯一的状态表达，边框也不表示完成。

字体离线可用，来源和许可可从“我的→开源许可”查看。桌面组件使用同一主色与习惯装饰，正文保持Android系统字体，外观页明确说明。实际截图、数据保留及未覆盖的厂商设备见STATUS。

UI02更新：主题为三种可视样卡、字体直接预览字形、边框直接预览图标；明暗选择采用低强调的选中状态。预览区压缩，恢复默认放工具栏辅助动作，底部保存和取消固定。习惯配色为带文字语义的色样，避免同色文字按钮无法表达实际颜色。支持320dp/160%，读屏具名和选中状态。
