# UI02 新功能界面重构与 FL19 回归

2026-11-07（承接11-06），用户指出新增功能UI质量不足，要求全面优化。保留既定冷白/蓝/淡紫/暖橙风格与真实功能。

问题：外观选项过度使用主动作按钮，预览和选项同权；数据页/导入页长说明挤占首屏；记录计数堆成彩色标签；配置页重复大标题和空白；统计切换缺乏稳定导航；桌面卡中心留白过多。不是只调颜色或圆角。

本轮取向：正文14、辅助12、条目16、页面标题22；标题与内容左对齐；16/20页边距、8/12内间距、16/22圆角。冷白#F6F8FE、墨色#18223B、主蓝#1656DF、记录紫#7252BE、暖橙#A95824继续使用，深色保持独立对比。主动作只用于保存/继续/确认；选择使用边框、勾选和轻底。48dp点击区域与系统字号继续保留。

- 外观：紧凑真实预览，主题以三色样卡展示，字体用中英文排版样卡，明暗/边框用图形选项；恢复默认为辅助动作。习惯装扮的配色改为具名色样，边框直接显示图标效果，保留24具名图标选择。
- 数据与备份：首屏清楚显示完整导出、恢复、旧习惯导入三个实际入口，风险和覆盖后果留在确认阶段。恢复副本独立突出；离线换机和文件范围说明折叠可读，不干扰主要操作。
- 导入：选文件/选内容/确认差异三步。条目以名称、类型、真实记录数和原频率为中心；跳过/未知/备注等细节按需展开。需要选择日程的项有明显状态，最后一步展示将追加的真实数量并确认差异；未确认不能写入。返回可改选择，取消不写。
- 统计：四个视图使用稳定导航，筛选和时间定位保持清楚；说明按需展开，真实数据优先。提醒中心压缩重复介绍，权限状态与可执行动作相邻。
- 桌面组件配置：用真实选中内容的小预览与列表；原生组件按空间安排日期、标题、状态和底部动作，减少无意义中央空白，尺寸小时优先可读内容。
- 通用：新增用于设置的选择卡、说明展开区、底部操作栏；明确按钮/选中/不可用语义，反馈可读，不添加假入口。原有数据规则、备份格式和免费范围不变。

工程和视觉分开验收。保持API28主用户数据，临时用户做操作；可用API35/36模拟器补系统验证，实际截图检视后修改。真机与手工TalkBack未具备证据时保留开放，不宣称完美或全设备无缺陷。FL19矩阵见SYSTEM-REGRESSION.md。
