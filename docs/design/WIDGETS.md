# FL16 桌面组件操作

2026-11-06，规则见 ADR0008。每个组件一个用户选择的内容，多个实例互不串配置。

## 视觉与流程

冷白 #F6F8FE、墨色 #18223B、主蓝 #1656DF、淡紫 #8062D6、暖橙 #D87A3D。系统字体，名称 18sp、状态 14sp、日期 12sp；深色独立映射。名称和日期左对齐，完成按钮位于底部，设置独立 48dp 点击区。细边圆角渐层将信息与动作区分，避免系统默认按钮。

```text
当前日期                     设置
所选习惯 / 小事名称
真实数量或完成状态
宽高足够时显示安排 / 任务类型说明
完成 / 输入总量 / 查看记录
```

- 长按桌面→组件→DayPanel 的习惯或小事组件→选择真实内容→保存返回桌面。没有可选内容时解释先在 App 创建，提供实际打开 App 入口；取消不创建绑定。
- 设置按钮再次进入同一配置页；选择和预览都不写入，保存才替换该实例，返回/取消保持旧选择。Launcher 的移除操作只删除绑定，保留业务记录。
- 布尔/小事主操作显示“完成”，打开独立记录 Activity，经现有规则写入后返回桌面；失败显示原因与关闭入口。已经完成时显示“查看记录”，可进入实际详情纠正，不做含糊的自动 toggle。
- 数量入口直接呈现既有总量面板，显示日期、当前值、目标与单位，只有保存/明确清除写入；退出返回桌面。不会累加固定数量。
- 周目标说明“本周 x/n 天”；非安排日可进入详情按用户意图记录。常驻标明“常驻 · 今天按需记录”，一次性保留完成日/计划日。归档不能记录，删除或恢复后的旧绑定要求重新选择。
- 空态、读取失败、过期动作均提供真实后续入口。配置列表复用 SoftPanel、SettingRow、AppAction 与 AppCanvas，固定保存/取消区；内容可滚动，长名称、窄屏、大字号、中英明暗一起检查。

## 系统边界

组件无需通知权限。午夜和后台刷新可受 Android 节电延迟；始终显示完整日期，旧日期按钮不写错日。强停后先打开 App；部分 Launcher 对尺寸及重新配置支持不同，组件自带设置入口。桌面绑定不包含在数据备份中，恢复/回退后重新选择。锁屏支持留待 FL19 按实际平台核验。
