# UX01 休息与分享

习惯详情增加“休息安排”操作行，进入后可暂停、选择休假范围、管理当前/未来休息；所选日期卡片有“跳过这天”或“取消跳过”。日常单列休息中的习惯，以明确状态和恢复入口呈现，避免静默消失。统计格显示暂停/休假/跳过语义，数量与真实事实不擦除。共享ChoiceSurface、ActionTile、EditorFooter、日期选择器，保持48dp与大字号滚动。

卡片详情增加“分享卡片”。页面先呈现实际导出预览，下面为“包含习惯名称”“包含心得”两个默认关闭的选项；心得允许编辑分享摘录，不改原文。固定“保存图片”和“分享”动作，等待生成期间禁重入；没有“已分享”伪成功。预览为可读原创海报，不包含应用内部按钮、数据库字段或系统栏。

本批保存前取消、恢复后旧页面、主题/语言/窄屏与键盘均需测试；设备用隔离用户，主用户原数据逐表比对。

休假选择器说明最多365天，超长范围给出明确提示，不写入。正在进行和已结束区间统一列为“休息安排与记录”，不会把当前暂停误叫历史。恢复按钮拥有独立语义节点；恢复前打开的旧页面失效时提示重新打开。分享预览按系统字体缩放，长海报根据尺寸降低输出倍率以保持在4096×16000边界内。空卡片禁用输出动作。
