# FL15 统计与历史

2026-11-06。规则见 [ADR0007](../adr/0007-history-statistics.md)。沿用冷白#F6F8FE、主蓝#1656DF、记录紫#8062D6、暖橙#D87A3D、墨色#18223B以及原有系统字体。共享字段、圆角面板、可达按钮和空态，图表必须对应真实值并提供逐日文本。

## 入口与操作

- 我的→统计与历史，七日回顾→统计与历史；习惯详情可直达该习惯统计。
- 顶部四个可换行的选项对应打卡表、习惯统计、年度日历、时间线。打卡表/年历可看全部习惯或筛选单个（含归档）；统计明确要求单习惯，避免混合数量和分母。
- 打卡表按自然周展示，前后切周/日历定位；日期与姓名为真实数据，名称列固定，日期区横向查看完整七天。单元格用符号与读屏文字区分状态。点击布尔格先显示日期、当前记录和确认完成/清除；数量格复用现有总量编辑面板。未来/开始日前不提供写入；归档数据可读，提示取消归档再纠正。
- 统计可选7/30/365天，先显示按日完成率及明确分母，再显示范围内当前/最长连续计划日；周目标单独列完整周结果、当前/最长连续周和进行中/部分周状态。数量每种历史单位单独卡片，显示实际合计、记录日均值/日数、可横滑的逐日柱形。零值有可见底线；下方每条实际记录展示日期/当时目标/单位，点击纠正。
- 年度日历上方展示全年实际记录总数及12个月份按钮，每月按钮显示实际记录数，默认当前月。下方以月历展示日期记录分布，点日期进入真实事件明细和未记录习惯。年度前后切换或日期定位均可；窄屏/大字号月历保持48dp起点击区，可横向滑动。
- 时间线按月或单日，可选全部/习惯/小事/手记/卡片，时间只精确到数据实际保存的日。打开各类条目使用现有真实编辑/详情，不加假入口。切月清除单日限定，类型保持；没有记录时提示换日期或类型。

## 数据可读性

履历未知与无记录区分，未知日期保留文本和数量事实但不算失败。归档当天按最终状态解释，过去已保存履历保持；历史归档缺失无法补造。完成率截至昨天，今日未结束；周中改版的部分周不混入完整周。数量不跨单位/习惯相加，均值按有记录日期计算并四舍五入至千分位。日历颜色只代表记录数，含零值，不代表达标比例。所有指标都在页面说明范围和缺失限制。

## 验收

工程验证覆盖状态判定、日期/闰年/年界、版本目标/单位、归档履历、周中变更/完整周、未知分母、显式纠正、取消/旧世代、单日时间线编辑及中英×明暗320dp/160%文字+280dp键盘。设备证据与限制写入STATUS，保留原用户数据，使用隔离用户做本轮操作验证。无外部五人走查前置。
