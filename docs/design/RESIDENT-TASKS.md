# 常驻小事 UI 与操作

2026-11-06。沿用现有冷白背景、蓝色操作、淡紫常驻/历史、暖橙普通待办状态。没有新增收费或专注入口。

- 新建小事在名称下提供“一次性 / 常驻”选项卡，下方立即说明规则；选常驻后隐藏日期字段，取消返回不创建任何数据。已有小事类型显示锁定，不能通过编辑意外转换。
- 小事页顶部是完成历史/归档入口与真实摘要；摘要区分“待处理的一次性小事”和“今天完成”。常驻区始终在普通日期分组之前，标记今天已做/今天未记录，完成后留在原位置便于复用。
- 常驻卡正文打开详情，勾选是显式完成/重开；更多菜单仅编辑/删除。每次修改成功才更新 UI，旧日期的当日按钮跨午夜拒绝写入。
- 常驻详情显示规则、开始日、所选日期、补记/撤销日期动作、全部实际完成记录；底部归档保留历史，永久删除明确包含历史。归档列表可进入详情恢复。
- 完成历史按日期浏览两类小事，显示类型与归档状态，点开可纠正；一次性小事仍按实际完成日显示。日历选择保留原生无障碍能力、使用已有主题。七日回顾的“小事完成”计入常驻日记录，习惯统计不受影响。
- 首次空态、没有历史、归档空态都有准确说明；中英、大字号和明暗沿用既有组件。无需外部走查才能交付，仍保留自动化与设备验证。

完整业务规则见 ADR 0004，本文件不代表小日常未公开行为已被实测确认。
