# UI04 页面重心与首屏操作

2026-11-07。用户要求可操作内容不被展示区挤到下面。沿用UI03色组和生活插画，本轮重排信息顺序和空间，不改业务规则或数据库。

| 页面 | 首要内容 | 辅助内容处理 |
|---|---|---|
| 日常 | 当日习惯与完成/记录动作 | 日期/筛选同行、紧凑周条、进度一行，删除顶部口号和大进度卡 |
| 小事 | 今天/逾期/收件箱待办 | 数量一行，历史为辅助入口，常驻说明放详情 |
| 手记 | 搜索/月份后的正文列表 | 去重框和重复标题，过滤项紧凑排列 |
| 我的 | 管理/外观/提醒/备份入口 | 免费宣言移到底部，常用入口上移 |
| 常用事项 | 可选模板/目标 | 删除二次大标题，插画缩到选择所需尺寸 |
| 外观 | 主题与明暗选择 | 预览一行，去掉重复组合说明，字体细节折叠，选项首屏可见 |
| 提醒 | 权限状态与习惯设置 | 介绍折叠，取消顶部口号 |
| 备份 | 导出/恢复/导入操作 | 解释移到说明区，风险确认仍在提交前 |
| 统计/回顾 | 表格/图表真实数据 | 保留图表作为本页重心，减少导航/标题间距 |
| 卡片册/分享 | 卡片内容 | 保留卡面；收藏筛选前不再放大介绍 |
| 详情/编辑 | 对象和当前动作/输入 | 不重复列表外观装饰，不压缩确认提示 |

常规正文14–16、条目17、标题22；48dp点击区不缩小。日常卡采用图标/名称与操作同列，数量/目标在名称下，进度细线；窄屏或大字号动作换到下一行，不横向挤字。页间靠功能色和内容结构区分，避免所有页面同一个大Hero模板。底栏压缩装饰留白保留四个可见标签。

验收：360×800常规字号首屏至少两个可操作习惯，320×800/160%至少一个完整主操作；小事第一个完成动作、手记第一条正文、我的管理/外观/备份、模板首批选择和外观主题选项真实可点击。用测试断言位置/命中及真实设备截图核对，旧记录与备份必须保留。

大字号超过130%时，日常以完整日期选择器替代常驻周条，为操作保留空间。折叠说明使用独立PageStorageKey，避免与列表滚动位置共用状态；设置页滚动/返回后应稳定。周目标卡仍显示本周达标/目标，不因布局精简丢失含义。

手记编辑也以正文输入为首要内容，正文提前至日期/关联习惯前；日期和关联仍可编辑，确认保存区固定。日常列表标题合并到进度行，避免重复统计栏挤压第四项。
