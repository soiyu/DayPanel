# DayPanel Flutter 产品范围 v1

更新 2026-11-05。最新决定：Flutter、Android 首发；先搭基座/UI；功能对标小日常，排除整个专注模块；全部免费。

## 产品与界面

清新、友好的习惯与日常记录工具。导航为「日常 / 小事 / 手记 / 我的」。日常显示当天习惯与日期；小事管理临时事项；手记记录碎念；我的管理习惯、回顾、外观、语言和数据。统计是独立页面，不与当日打卡混成一个综合分数。

视觉沿用负责人已选 Stitch 冷白、浅蓝、淡紫、少量暖橙，大圆角与轻盈层次。功能和信息组织参照小日常，独立设计资源，不复制品牌/插画/商业文案。

## 功能地图和首批实现

完整地图见 [小日常逐项对标](XIAORICHANG-PARITY.md)：Android 3.1.0 官方说明为主，iOS 10.4.44 为补充，未知细项明确标注。无需外部走查才能开工；自动化和系统正确性测试继续执行。

已交付基座、四栏 UI、SQLite、习惯/数量记录、临时小事、文本手记、近七日回顾、习惯管理、中英文与主题。M2 增加情境/习惯组/排序、每日/星期/间隔/周目标、计划版本、完整文件备份恢复，以及 FL11 习惯提醒、FL12 常驻小事/完成历史、FL13 关联日志/月浏览/搜索、FL14 成就卡/收藏/心得/反馈、FL15 打卡表/量化统计/年历/时间线。无预置演示记录。FL16 已实现习惯/小事桌面组件，FL17 已提供免费外观与习惯装扮。

## 明确决定

- 所有产品功能免费，不做 Pro、订阅、买断、SKU、试用或付费额度。组件、装扮、统计、导出也免费。
- 不以广告替代收费；无广告/分析 SDK，本地使用不强制账号。
- 排除专注计时及全部附属功能：正/倒计时、番茄、音乐、循环/休息、专注记录/补记/报表/组件。普通习惯提醒与数值记录保留。
- 暂不生成 iOS。iCloud 不可直接用于 Android；等价数据方案另定，先做本地备份，不伪称已支持同步。
- 不继续混入其他竞品的协作、AI、日历项目管理或健康自动采集。

## 数据规则

习惯、日记录、任务与完成日、手记独立存储。SQLite v10 不修改旧 Loop 数据。创建日前和未来日不允许习惯/常驻完成；频率编辑不改历史事实。数量用整数千分位，零值与未记录不同。一次性任务完成按实际日记账，重开保留计划日。常驻按当地日最多记一次，不生成重复实例；归档保留日期历史，永久删除有确认。写入成功后更新 UI，失败可重试。具体见 [ADR0004](../adr/0004-resident-tasks.md)。

数量为至少目标；频率有每日/指定星期、每 N 天、每自然周 N 个达标日。已有目标/单位/频率改动从明天生效，历史使用日期对应版本；周目标计达标日，不把不同日期的数值相加。UX01已支持暂停/休假/跳过，休息不算完成或失败，期间拒绝新增记录并暂停提醒；原记录保留。回顾仍展示实际记录计数，不用当前计划倒推迁移前完成率。完整规则见 [ADR 0002](../adr/0002-plans-and-backup.md)。

提醒配置独立于计划，可即时启停或修改时刻，触发时读取实际计划版本。保存时可请求通知权限，拒绝不丢设置；可选准时权限，缺失时标准闹钟可能延迟。通知点击仅打开记录界面，不写完成；稍后10分钟不跨日。详情见 [ADR0003](../adr/0003-habit-reminders.md)。

FL13 手记支持独立或关联一个习惯，记录日期可编辑、默认今天；日志不等于打卡。正文搜索与月份/单日/习惯筛选同时生效，可切换全部月份。归档保留关联，删除习惯仅解除日志关联并保留文字与日期。SQLite10 与备份 schema10 兼容旧库和 schema2/3/4/5/6/7/8/9；详见 [ADR0005](../adr/0005-associated-journal.md)。

FL14 每天最多一张成就卡，按当天未归档的每日/星期/间隔计划全部达标判定，周目标不算每日必做，筛选不改变判定。已获卡片和当时完成快照在撤销/改计划/删习惯后保留，心得可编辑清空，收藏可筛选。默认关闭的声音/触感可分别开启，系统静音和勿扰仍生效。全部免费，无随机付费抽卡；见 [ADR0006](../adr/0006-achievement-cards.md)。

FL15 单习惯完成率按历史计划与已知归档履历计算至昨天，未知日期不计失败，周目标完整周单列；当前/最长连续性仅限所选范围。量化按历史单位分别汇总，零值有记录、缺值不补零。年历表示实际记录数，时间线汇总习惯/小事完成/手记/成就卡并直达编辑；详见 [ADR0007](../adr/0007-history-statistics.md)。

FL16 两种 Android 桌面组件可各自绑定一个真实对象；多实例独立选择、保存/取消、重新配置、删除和尺寸适配。布尔/小事只写显式完成，已完成进入真实详情；数量直接打开总量输入，保存才写入。原生只读业务快照，独立 Flutter Activity 复用同一事务/计划/卡片/提醒规则。绑定属于设备状态，不进入备份；恢复后需重新选择，旧 generation/旧日期/旧配置动作拒绝。系统更新、开机、包更新、日期/时区改变和 App 操作刷新；节电或强停限制仍适用，不增加通知权限要求。见 [ADR0008](../adr/0008-home-widgets.md)。

FL17 外观页提供三种主题、系统/浅/深模式、系统字体/本地Noto Serif SC、默认柔和底/圆环/无边框，预览后保存，返回/取消不写入。习惯24个图标保留原六个含义，可单独配色/边框，不更改计划、统计或成就规则。外观与装扮进入schema8备份、恢复前副本和回退；兼容旧schema2–7。未知枚举拒绝导入，旧页面受generation保护。全部免费，无在线字体下载；桌面系统字体限制见ADR0009。

FL18 可选择Loop数据库21–25版.db追加习惯与原始记录，经过只读校验/预览/选择/差异确认后写入。滚动频率由用户明确选新安排，历史履历未知不算失败，数值保留千分位；旧提醒/派生得分/旧扩展小事场景不迁移，至多目标不强转。重复身份跳过、不覆盖本机；导入前完整副本可回退。FL18交付时SQLite8/schema8保持，来源说明/备注使用已有手记字段进入备份。Android离线换机为手动完整文件导出/传输/恢复，不提供云或自动同步。详见ADR0010。
