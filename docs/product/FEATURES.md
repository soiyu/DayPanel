# DayPanel Flutter 产品范围 v1

更新 2026-11-05。最新决定：Flutter、Android 首发；先搭基座/UI；功能对标小日常，排除整个专注模块；全部免费。

## 产品与界面

清新、友好的习惯与日常记录工具。导航为「日常 / 小事 / 手记 / 我的」。日常显示当天习惯与日期；小事管理临时事项；手记记录碎念；我的管理习惯、回顾、外观、语言和数据。统计是独立页面，不与当日打卡混成一个综合分数。

视觉沿用负责人已选 Stitch 冷白、浅蓝、淡紫、少量暖橙，大圆角与轻盈层次。功能和信息组织参照小日常，独立设计资源，不复制品牌/插画/商业文案。

## 功能地图和首批实现

完整地图见 [小日常逐项对标](XIAORICHANG-PARITY.md)：Android 3.1.0 官方说明为主，iOS 10.4.44 为补充，未知细项明确标注。无需外部走查才能开工；自动化和系统正确性测试继续执行。

已交付基座、四栏 UI、SQLite、习惯/数量记录、临时小事、文本手记、近七日回顾、习惯管理、中英文与主题。M2 第一批增加情境/习惯组/排序、每日/星期/间隔/周目标、计划版本与完整文件备份恢复。无预置演示记录。提醒、常驻小事、关联日志、成就卡、全年统计、组件和完整装扮仍按后续任务完成。

## 明确决定

- 所有产品功能免费，不做 Pro、订阅、买断、SKU、试用或付费额度。组件、装扮、统计、导出也免费。
- 不以广告替代收费；无广告/分析 SDK，本地使用不强制账号。
- 排除专注计时及全部附属功能：正/倒计时、番茄、音乐、循环/休息、专注记录/补记/报表/组件。普通习惯提醒与数值记录保留。
- 暂不生成 iOS。iCloud 不可直接用于 Android；等价数据方案另定，先做本地备份，不伪称已支持同步。
- 不继续混入其他竞品的协作、AI、日历项目管理或健康自动采集。

## 数据规则

习惯、日记录、任务与完成日、手记独立存储。新 SQLite v1 不修改旧 Loop 数据。创建日前和未来日不允许习惯完成；频率编辑不改历史事实。数量用整数千分位，零值与未记录不同。任务完成按实际日记账，重开保留计划日。写入成功后更新 UI，失败可重试；删除确认，归档保留历史。

数量为至少目标；频率有每日/指定星期、每 N 天、每自然周 N 个达标日。已有目标/单位/频率改动从明天生效，历史使用日期对应版本；周目标计达标日，不把不同日期的数值相加。暂停与日志关联后续实现。回顾仍展示实际记录计数，不用当前计划倒推迁移前完成率。完整规则见 [ADR 0002](../adr/0002-plans-and-backup.md)。
