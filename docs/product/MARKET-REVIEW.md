# DayPanel 市场评测与 Plus 付费策略

更新 2026-11-12。范围：Android 习惯追踪 / 日常记录类产品，重点看“哪些能力被用户接受为付费点”，以及 DayPanel 在不引入账号、云同步、广告、AI、专注计时的约束下，还能增加什么真正有用的 Plus 功能。

> 说明：以下价格与功能来自公开商店页、开发者官网和第三方评测，页面日期见文末来源。商店价格会按地区、促销和 A/B 测试变化；本文只用于产品决策，不构成最终定价。上架文案必须再次核对官方页面。

## 1. 结论

1. **市场的主流商业模式是“免费基础 + 订阅”，一次性买断是稀缺卖点。** Habitify、小日常、Daylio、Habitica 都以订阅或订阅+内购为主；Streaks、HabitNow、HabitKit 保留一次性买断。DayPanel 已经选择一次性 Plus（ADR0016），这本身就是差异化，不应改成订阅。
2. **竞品的付费点集中在五类：**
   - 解除免费层限制（习惯数量、历史范围、提醒数量）；
   - 高级统计 / 洞察 / 关联分析；
   - 桌面组件与视觉装扮；
   - 云同步 / 自动备份 / PDF 导出；
   - 模板、挑战、健康数据自动完成等增值内容。
3. **DayPanel 不能跟随的付费点：** 云同步、账号、AI 教练、社交/挑战、专注计时、健康自动采集。这些要么被产品决定排除，要么需要额外权限与服务端，和“纯本地、无账号”冲突。
4. **DayPanel 已经覆盖的 Plus 价值：** 组合桌面、逐次明细、周累计目标、周/月复盘 PNG、额外装扮、日历副本、CSV 导出。它们解决“记录得更细、回顾得更好看”，但还缺少一个把已有数据转成**可执行结论**的能力。
5. **因此本批新增“深度洞察（Insights）”作为 Plus 核心功能。** 它复用现有习惯、计划、记录、休息、手记、小事和事件账本，不新增权限、不上传数据、不需要服务端；同时直接对标 Habitify / Daylio / HabitKit 的“高级统计”付费点，且比单纯多几张图表更实用：用户能看到本周哪一天最弱、哪两个习惯经常一起完成、连续中断发生在哪里、本月与上月相比如何。
6. **免费边界不变：** 基础记录、完整备份/恢复/回退、CSV 导出、已存数据查看与纠正继续免费。Insights 是新增的高级视图，不移走任何原有免费功能。

### 2.1 价格锚点

- **低价一次性**：Streaks $5.99；HabitNow 常见区间 $0.99–$11.99。
- **中高价一次性**：Habitify lifetime 官网 $59.99 起，App Store 另有 $119.99 档；HabitKit 终身价按地区浮动。
- **订阅**：Habitify Premium $2.49/月（年付）；Habitica $4.99/月；小日常按 3/6/12 个月续费。
- **DayPanel 建议**：Plus 作为“一次买断、含后续 Plus 更新”的产品，首发价建议落在 **US$6.99–$9.99**（或等值本地价格），不要低到 $2.99 以下——否则会削弱“高级能力包”的感知，也不足以覆盖后续维护。正式价格由负责人在 Play Console 设置；可用首发折扣做冷启动，但不做“限时焦虑”式弹窗。

## 4. 新增 Plus：深度洞察（Insights）

### 4.1 用户问题

现有统计能回答“完成率多少、哪几天打了卡”，但不容易回答：

- 这个月比上个月进步了吗？
- 我星期几最容易掉链子？
- 哪个习惯连续最稳、哪个总是断？
- 哪两个习惯经常一起完成？（只做相关性提示，不宣称因果）
- 周目标习惯是否真的在按周达成？
- 手记和小事有没有随着习惯一起变化？

### 4.2 范围

- 时间窗：最近 30 / 90 / 365 天；今天不计入完成率，避免“今天还没打卡”拉低数字。
- 总览：完成率、与上一个等长周期对比、全勤天数、活跃天数、手记数、最佳连续。
- 星期：周一至周日完成率，标记最强/最弱一天（样本不足不标记）。
- 习惯：每个习惯的完成率、趋势、当前/最佳连续；周目标习惯单列“达标周/应达标周”。
- 组合：两个习惯的共同完成次数与 lift；只显示样本足够的组合，并明确“相关不等于因果”。
- 手记与事件：手记篇数/字数/天数、记录事件数。
- 月度：时间窗 ≥120 天时显示逐月完成率柱状图。
- 空状态：没有足够数据时说明“先记录几天再来看”，不编造图表。

### 4.3 为什么它是“更实用”的付费点

- **复用已有数据，边际成本低**：不需要新表、新权限、新服务端，schema 仍是 12。
- **每次记录都会增加价值**：用户用得越久，洞察越有意义，和“一次买断”不冲突。
- **与免费统计形成清晰层级**：免费统计回答“发生了什么”，Plus 洞察回答“接下来怎么调整”。
- **可分享、可截图**：后续可复用复盘 PNG 管线做“洞察卡片”，但本批先保证页面本身准确。
- **符合隐私定位**：所有计算在本地完成，不上传习惯、手记或事件。

### 4.4 验收与限制

- 领域层：`lib/domain/insights.dart`，8 个单元测试覆盖分母、休息/暂停/跳过、周目标、组合 lift、环比、空窗口、月度分桶，以及所有星期持平时不强行标记最稳定日。
- UI 层：`lib/presentation/insights.dart`，3 个 widget 测试覆盖锁定态、30/90 天数据、首页入口。
- 已有相关页面回归：plus、首页布局、导航可读性、Plus 操作面板共 21 项通过。
- `dart format`、`flutter analyze` 通过。
- 已完成：`flutter test` 全量 453 项通过、`dart format` 与 `flutter analyze` 无问题。尚未完成：真机/TalkBack、自然完整周期数据验证；不得把“测试通过”写成“设备验收完成”。
- 洞察是描述性统计，不是医疗、心理或因果建议；文案避免“治愈”“保证养成”等承诺。

## 5. 后续候选（本批不做）

| 候选 | 价值 | 成本/风险 | 判断 |
| --- | --- | --- | --- |
| 年度 PDF/长图报告 | 高，适合分享与付费 | 复用现有 PNG 管线，中等 | 下一批优先候选；先看 Insights 使用反馈 |
| 自定义报告周期/模块 | 中 | 低，但容易变成“设置项堆砌” | 可随后做 |
| 自动备份到用户选择的文件夹 | 高 | SAF/定时任务；不能影响免费手动备份 | 需单独 ADR，暂缓 |
| 高级提醒（位置/完成情况触发） | 中 | 定位权限、后台限制、隐私 | 不做 |
| Health Connect 自动完成 | 中 | 权限、数据准确性、审核 | 不做 |
| 更多主题/图标包 | 低-中 | 美术成本高、差异化弱 | 不优先 |
| 习惯模板/挑战 | 中 | 内容运营与“不注入演示数据”冲突 | 不做预置数据，可做用户自建模板 |

## 6. 发布与文案注意

- Play 商品仍为单一非消耗型 `daypanel_plus`；价格、地区可用性和税费在 Console 配置，代码只读取真实报价。
- 商店文案把 Insights 放在 Plus 区，不要放进“免费核心功能”；免费区继续强调备份/导出/无广告/无账号。
- 不使用“最科学”“保证养成”“治疗拖延”等医疗或效果承诺；组合洞察必须带“相关不等于因果”说明。
- 新个人开发者账号的 12 人/14 天封闭测试、真实付款/退款/恢复、签名与公开政策地址仍需负责人完成；代码与本地验证不能替代 Console 验收。
- 发布前重新核对本文价格与竞品功能；价格和商店政策可能已变化。
